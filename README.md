# FinMaster

Десктоп-программа учёта заказов: Python-сервер и HTML-интерфейс в собственном окне (WebView2 на Windows).

## Запуск

Нужен Python 3.10+.

```bat
run.bat
```

или:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Откроется отдельное окно FinMaster, не вкладка системного браузера. Если пакет `pywebview` недоступен, программа откроет интерфейс в обычном браузере (сохранение тогда идёт через скачивание файла).

## Файлы отчётов

Каждый отчёт — файл `.fmaster` (JSON). Можно создавать новые, открывать существующие и вести список недавних, как в Excel.

- **Автосохранение** — по галочке, только после первой ручной записи на диск.
- Без галочки файл пишется по кнопке **Сохранить** (Ctrl+S) или **Сохранить как**.
- При закрытии с несохранёнными изменениями программа предлагает сохранить отчёт.

## Возможности

- Заказ: номер, заказчик, название.
- Несколько типов/позиций на один заказ: продукт, количество и единица (шт., м², м, мин и свои), цена, скидка %, даты, оплата, долг, итог, статус.
- Редактируемые статусы, единицы и типы заказа.
- Дашборд, фильтры, сравнение периодов, графики, экспорт CSV.
