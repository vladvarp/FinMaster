Обновление

Кнопка в верхней панели, между шестерёнкой настроек и кнопкой «?». При запуске программа про обновление не спрашивает: свечение на кнопке само показывает, есть ли что скачать.

Свечение кнопки

  • Янтарное — на GitHub версия новее. Подсказка: «Есть обновление». Качаются только файлы, которых нет или которые отличаются.
  • Красное — своей даты нет, а файлы в папке не совпали с репозиторием. Подсказка: «Возможно, файлы повреждены». То же свечение с восклицательным знаком, если проверка целостности нашла расхождение. Подсказка тогда: «Целостность программы нарушена». Скачивается полный набор.
  • Без свечения — это последняя версия. Окно так и пишет. Кнопка «Скачать» забирает полный набор ещё раз. «Закрыть» окно просто прячет.

Пока программа стоит в папке с .git, кнопка неактивна: подсказка «В репозитории обновление выключено».

Окно

Заголовок «Есть обновление», «Версия старая» или «Обновление». Справа «О программе»: копирайт V.Ar Production с годом из commit.txt, лицензия GNU GPL версии 3, ссылки на Telegram и GitHub.

Две карточки. Текущая версия — янтарная, если установленная отстаёт, и красная, если целостность нарушена. На GitHub — бирюзовая. У каждой дата и код коммита. Если даты совпали и это последняя версия, карточки «На GitHub» нет. Если GitHub не ответил, у текущей остаётся дата из commit.txt, а не «дата неизвестна», у новой написано «сервер не ответил».

Кнопка i стоит у новой версии, когда обновление есть, и у текущей, когда нарушена целостность и второй карточки нет. Она открывает список: каких файлов нет и какие изменены. Повторное нажатие список прячет.

Под карточками — путь «От этой версии до последней»: код, дата, имя и текст коммита. Установленный шаг помечен «установлена», последний — «последняя». Вся история показывает весь путь, «Только новое» возвращает отрезок до последней. История запрашивается у GitHub заново при каждом открытии окна.

Обновить закрывает окно и запускает update.vbs. Отчёты в Документы\FinMaster не подменяются. Новая версия при целой программе качает только отличия. Полный набор качается, если целостность нарушена, файлы повреждены или это повторное скачивание последней версии. Когда снимок готов, окно программы открывается снова. Несохранённый отчёт перед этим спрашивает, записать ли его.

Проверить целостность

Кнопка видна, только когда даты текущей версии и GitHub совпали. Она сверяет файлы программы с репозиторием. Запускалка, свой Python и сама строка даты в commit.txt в сверку не входят.

Если файлы совпали, зелёным пишется «Целостность не нарушена». Если файл другой или его нет — «Целостность программы нарушена». Пометка дописывается в commit.txt и держится, пока следующая сверка не совпадёт. Пока она есть, при каждом запуске файлы сверяются снова, а кнопка обновления горит красным с восклицательным знаком. i у красной карточки показывает тот же список отличий.

Список файлов, которые качает обновление, лежит во временном FinMaster-update.txt, не в config.json.
