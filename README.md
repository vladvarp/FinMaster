# FinMaster

Десктоп-программа учёта заказов: Python-сервер (Flask) и HTML-интерфейс в собственном окне (WebView2 на Windows). Всё, что нужно бухгалтеру и финансисту небольшой мастерской или студии: заказы с позициями, оплаты и долги, дашборд, аналитика периодов, платёжный календарь, снимки для заказчика и управление с телефона.

Данные лежат в одном файле отчёта `.fmaster` — как книга Excel. Никаких внешних серверов и облаков: программа работает на компьютере, а телефон подключается напрямую к нему.

## Быстрый старт

Нужен Python 3.10 или новее.

```bat
run.bat
```

Или вручную:

```powershell
python -m pip install -r requirements.txt
python app.py
```

Откроется отдельное окно FinMaster, а не вкладка системного браузера. Если пакет `pywebview` недоступен, программа откроет интерфейс в обычном браузере — тогда сохранение файла идёт через скачивание, а системные диалоги выбора файла недоступны.

Зависимости: `flask>=3.0.0`, `pywebview>=5.0`.

---

## Как это устроено

- **`app.py`** — Flask-сервер: раздаёт интерфейс, отвечает на API-запросы, работает с файлами и диалогами Windows, поднимает окно pywebview и (по желанию) удалённый доступ.
- **`frontend/`** — интерфейс: `index.html` + `app.js` + `styles.css` для компьютера, `mobile.html` + `mobile.js` + `mobile.css` для телефона, `charts.js` и `cloud.js` — графики и живое облако заказов на canvas (без внешних библиотек).
- **`backend/`** — модули: документ и нормализация (`document.py`), настройки и недавние файлы (`storage.py`), системные диалоги (`dialogs.py`), буфер обмена (`clipboard.py`), генерация QR (`qr.py`), сессия телефона (`remote.py`), ngrok-туннель (`tunnel.py`), Telegram-бот (`telegram.py`).

Сервер слушает всю локальную сеть (`0.0.0.0`), но запросы с других адресов пускает только к мобильному интерфейсу и только с правильным токеном сессии. Порт по умолчанию **17891**; если занят, программа сама берёт следующий свободный из 12 соседних, а в крайнем случае — любой свободный, и запоминает его.

## Файлы отчётов

Каждый отчёт — файл `.fmaster` (внутри обычный JSON). В нём лежат заказы с позициями, справочники, заказчики и настройки интерфейса (ширина столбцов, тема снимка, срок оплаты, горизонт прогноза).

- **Новый отчёт** — `Ctrl+N` или кнопка «Новый».
- **Открыть** — `Ctrl+O`, кнопка «Открыть» или строка в списке недавних на стартовом экране.
- **Сохранить** — `Ctrl+S`, **Сохранить как** — `Ctrl+Shift+S`.
- **Автосохранение** — галочка в боковой панели. Работает только после первой ручной записи на диск: программе нужно знать путь к файлу.
- При закрытии с несохранёнными изменениями программа спросит подтверждение и предложит сохранить.
- Список недавних хранит до 15 файлов; лишние строки можно убрать крестиком.

Запись на диск атомарная: файл сначала пишется во временный, потом подменяет старый — питание пропало, отчёт не потерялся.

## Интерфейс

**Стартовый экран** — список недавних отчётов, кнопки «Новый отчёт», «Открыть файл» и переключатель темы.

**Боковая панель** — название текущего отчёта (его можно править прямо здесь), путь к файлу, точка «есть несохранённые изменения», навигация по разделам, кнопки файловых операций и галочка автосохранения. Панель сворачивается кнопкой `☰` — остаются только иконки разделов.

**Верхняя панель** — поиск по отчёту, кнопка командной палитры, отмена/повтор, кнопка «Телефон», переключатель темы, возврат к списку отчётов, экспорт CSV и подсказка по горячим клавишам.

**Темы** — светлая и тёмная, переключаются в любом месте программы и запоминаются между запусками. Тёмная тема применяется и к мобильному интерфейсу.

**Поиск (`Ctrl+F`)** ищет по номеру заказа, заказчику, названию и продукту, сразу фильтруя список заказов.

**Тосты** — короткие уведомления внизу экрана. У разрушающих действий (удаление заказа, строки, заказчика) в тосте есть кнопка «Отменить».

## Раздел «Заказы»

Главный рабочий раздел. Заказ — это карточка с общими полями и таблицей позиций.

**Шапка заказа:** номер, заказчик (с подсказками из справочника), название. Кнопка `i` открывает заметки к заказу; если заметка есть, кнопка подсвечивается.

**Общие поля заказа** применяются сразу ко всем позициям: скидка %, статус, тип заказа, дата заказа, дата оплаты. Удобно, когда заказ оплатили целиком или сдвинули срок.

**Кнопка «Оплатить все типы»** записывает в каждую строку её итог и, если оплата покрывает сумму, ставит статус «оплачено».

**Таблица позиций** — столбцы: тип заказа, продукт, количество, единица, цена, скидка %, дата заказа, оплачено, дата оплаты, не оплачено, итог, статус. Итог, «не оплачено» и проценты считаются на лету.

- Строки перетаскиваются мышью за левую ручку, порядок сохраняется в файле.
- Ширина любого столбца тянется за границу заголовка и запоминается в отчёте.
- В количестве, цене и скидке работают **формулы**: `2+3*4`, `1200/3`, `(5+2)*100`. Вместо `*` можно писать `x` или `×` (`3x250`), запятая сама превращается в точку. В ячейке остаётся формула, в итогах — результат.
- Кнопки в строке: дублировать (`⧉`) и удалить (`✕`).

**Фильтры-чипы** над списком: Все, С долгом, Оплаченные, Этот месяц, Без цены — с количеством заказов в каждой группе.

**Сортировка:** сначала новые, сначала старые, по номеру, по заказчику, по сумме ↓.

**Действия с заказом:** «Снимок» (картинка для заказчика), «Дублировать», «Удалить». Кнопка «Снимок заказов» в тулбаре собирает снимок сразу по нескольким заказам.

## Раздел «Дашборд»

**KPI-плитки:** количество заказов и позиций, сумма к оплате после скидок (и отдельно — без отменённых), оплачено с процентом сбора, не оплачено.

**Инсайты** — восемь готовых выводов: выручка за месяц со сравнением с прошлым, прогноз до конца месяца по текущему темпу, средний чек, собираемость оплат, лучший заказчик, хит продаж, долги старше 30 дней и количество заказов за 30 дней против предыдущих 30. У метрик со сравнением есть чип тренда `+12%` / `−8%`.

**Графики:** выручка по дням (последние 14 дней) и распределение сумм по статусам — цвета берутся из справочника статусов.

**«Требуют внимания»** — позиции с долгом и заказы из чёрного списка. **«Последние заказы»** — быстрый переход к свежим заказам.

**Фокус заказа с телефона.** Когда с телефона открывают конкретный заказ, наверху дашборда появляется блок «с телефона» с цифрами именно этого заказа: кнопка «Открыть в заказах» ведёт к карточке, «Весь отчёт» возвращает общие показатели.

---

## Раздел «Аналитика»

**Фильтры мониторинга:** дата с/по, поле даты (дата заказа или дата оплаты), группировка (часы, дни, недели, месяцы), статус, тип заказа, заказчик, продукт, единица измерения, сумма от/до, галочка «Только долги». Пресеты периода: Сегодня, 7 дней, Этот месяц, Этот год. Кнопка «Сбросить» возвращает всё в исходное.

**Сравнение периодов A и B** — два независимых интервала с итогами по каждому и графиком сравнения метрик (каждая метрика в своей шкале, чтобы выручка не «съедала» количество заказов).

**График «Динамика»** строится по выбранной группировке.

**Таблица «Найденные позиции»** — все строки отчёта, попавшие под фильтры, с итогами по ним.

## Раздел «Касса»

Платёжный календарь и работа с дебиторкой — раздел о том, *когда* придут деньги, а не только сколько их всего.

**Настройки сверху:** срок оплаты в днях от даты заказа (0–365, по умолчанию 14) и горизонт прогноза (14, 30, 60 или 90 дней). Оба параметра хранятся в файле отчёта. Кнопка «Копировать сводку» кладёт в буфер текстовую выжимку по кассе — удобно отправить руководителю.

**KPI:** поступит за 7 дней (и за 30), просрочено с максимальной задержкой, средний фактический срок оплаты против договорного, вся дебиторка с процентом собираемости.

**Прогноз поступлений** — накопительный график с двумя линиями: план по сроку оплаты и реалистичный прогноз с учётом платёжной дисциплины заказчиков (насколько каждый из них исторически задерживает оплату).

**Долг по заказчикам** — круговая диаграмма, крупные должники отдельно, остальные в «Прочие».

**Платёжный календарь** — плитки по дням с суммами ожидаемых поступлений. Клик по дню фильтрует реестр дебиторки, повторный клик снимает фильтр.

**Старение дебиторки** — полоса и разбивка долга по корзинам: срок не наступил, просрочка 1–7 дней, 8–30, 31–60, больше 60 дней и отдельно позиции без дат. Под таблицей считается «безнадёжная зона» — доля долга с просрочкой больше 30 дней. Клик по корзине фильтрует реестр.

**Реестр дебиторки** — список неоплаченных позиций с ожидаемой датой, суммой и просрочкой. Действия в строке: отметить оплату одной кнопкой, скопировать готовый текст напоминания заказчику, открыть заказ, отфильтровать реестр по этому заказчику.

**«Кто должен»** — таблица по заказчикам: долг, число позиций, дисциплина (средняя задержка оплаты относительно срока).

## Раздел «Облако»

Интерактивная графическая карта отчёта. Она показывает данные как трёхуровневый граф: **заказчик → заказ → позиция (подзаказ)**. Круги — заказчики и позиции, ромбы — заказы, линии между ними показывают принадлежность. Размер, цвет и красная дуга вокруг узла кодируют финансовое состояние.

**Четыре геометрии:**

- **Умные кластеры** — заказчики образуют отдельные «галактики», вокруг них собираются заказы и позиции. Подходит для поиска крупных клиентов и концентрации долга.
- **Орбиты заказов** — заказы распределяются по спирали, позиции образуют орбиты вокруг своих заказов.
- **Финансовая ось** — заказы раскладываются слева направо по дате, по вертикали — по сумме.
- **Созвездия работ** — позиции группируются по типу работы, а между заказчиками с похожим портфелем рисуются пунктирные мосты (минимальное остовное дерево + общие типы).

**Визуальное кодирование:** цвет переключается между статусом, заказчиком, оплатой и типом работы; размер — между суммой, долгом, количеством и одинаковыми узлами. Красная дуга вокруг узла — доля долга. Полупрозрачные оболочки отмечают кластеры заказчиков. Кнопка `♨` включает тепловую карту долга.

**Поиск и фильтрация:** поле ищет по номеру, заказчику, названию, заметкам, продукту, типу, статусу и единице. Клавиша `/` сразу переводит в поиск, совпадения пульсируют на карте. Тумблер **«Только долг»** оставляет лишь неоплаченные позиции. KPI над картой пересчитываются по видимой выборке.

**Управление картой:**

- колесо — масштаб относительно курсора, перетаскивание пустого места — панорама;
- узел можно перетащить вручную, клик фиксирует его в инспекторе справа;
- двойной клик или `Enter` открывает заказ в разделе «Заказы»;
- стрелки переходят между соседними узлами, `F` вписывает весь граф, `T` запускает автотур по очагам долга;
- клик по мини-карте прыгает в выбранную область;
- кнопки `+` / `−` меняют масштаб, `⊙` вписывает граф, `⛶` открывает полный экран;
- `Aa` скрывает подписи, `◉` ставит физику на паузу;
- при выборе узла несвязанные данные приглушаются, по связям бегут импульсы.

Инспектор показывает оборот, оплату, долг, собираемость, статус, тип, количество и дату. Из него можно открыть заказ, создать снимок, оставить на карте связи заказчика или центрировать выбранный узел.

Движок написан специально для FinMaster на Canvas 2D: force-directed физика, пространственная сетка столкновений, выпуклые оболочки кластеров, тепловое ядро долга, живой фон, адаптивная детализация и поддержка `prefers-reduced-motion`. Цвета и фон следуют светлой или тёмной теме.

## Раздел «Заказчики»

Справочник контактов: имя, организация, телефон, почта, адрес, рейтинг звёздами, время совместной работы (считается с даты первого заказа) и количество заказов. Новые имена, введённые в заказах, попадают в справочник автоматически; имя из справочника подсказывается при заполнении заказа.

---

## Раздел «Справочники»

Четыре редактируемых списка, всё перетаскивается и переименовывается:

- **Статусы заказа** — имя и цвет. Флаг «оплачено» помечает статус полной оплаты (такой статус в отчёте один). Замок защищает статус от массовой смены через общее поле заказа — так «Отменено» или «Черный список» не снесёт одним кликом.
- **Единицы измерения** — по умолчанию `шт.`, `м²`, `м`, `мин`; можно добавить свои.
- **Типы заказа** — по умолчанию Производство, Услуга, Поставка, Монтаж.
- **Продукты** — название и единица по умолчанию, которая подставляется в столбец «Ед.» при выборе продукта.

Статусы по умолчанию: Новый заказ, Выполняется, Ожидание, Не оплачено, Оплачено, Отменено, Аннулирован, Черный список.

## Снимок для заказчика

Красивая картинка или текст с составом заказа — то, что отправляют клиенту вместо скриншота таблицы.

- **Заголовок** снимка задаётся вручную.
- **Оформление** — 7 тем: Изумруд, Графит, Индиго, Золото, Вишня, Минимал, Ночь.
- **Поля** — 16 доступных: номер, имя заказчика, организация, название, тип/работа, продукт, количество, дата заказа, статус, цена, скидка, сумма позиции, оплачено, не оплачено, дата оплаты, итоги заказа. Готовые наборы: «Только работы» (без цен — для согласования состава), «Счёт» (с ценами и итогами), «Все поля».
- **Скрытие** подписей полей и даты формирования — для совсем лаконичного вида.
- **Выбор заказов и строк** — можно исключить отдельные позиции из снимка.
- **Предпросмотр** обновляется на ходу.
- **Результат:** сохранить PNG, скопировать PNG в буфер, скопировать текстом.

Набор полей и выбранная тема запоминаются в файле отчёта.

## Экспорт CSV

Кнопка «Экспорт CSV» в верхней панели выгружает все позиции отчёта: номер, заказчик, название, тип, продукт, количество, единица, цена, скидка, итог, оплачено, не оплачено, даты заказа и оплаты, статус. Разделитель — точка с запятой, кодировка UTF-8 с BOM, так что Excel открывает файл без танцев с импортом.

## Горячие клавиши

Подсказка по клавишам всегда доступна по `F1` или кнопке `?`.

### Файл

| Действие | Клавиши |
| --- | --- |
| Сохранить | `Ctrl+S` |
| Сохранить как | `Ctrl+Shift+S` |
| Открыть отчёт | `Ctrl+O` |
| Новый отчёт | `Ctrl+N` |

### Общее

| Действие | Клавиши |
| --- | --- |

## Командная палитра

`Ctrl+K` открывает палитру: строка ввода и список команд с группировкой. Навигация `↑` `↓`, выполнение `Enter`, закрытие `Esc`.

Палитра умеет:

- переходить в любой раздел — Дашборд, Заказы, Аналитика, Касса, Облако, Заказчики, Справочники;
- выполнять действия — сохранить, сохранить как, открыть, создать, экспорт CSV, снимок заказов, отмена/повтор, подсказка;
- открывать кассовые сценарии — например, показать просроченные долги или скопировать сводку;
- искать по содержимому отчёта: наберите номер заказа, имя заказчика или название продукта — палитра предложит перейти к нужной карточке.

Отмена и повтор работают на уровне документа: любое изменение (правка ячейки, удаление строки, массовая смена статуса) откатывается `Ctrl+Z`, в том числе если действие пришло с телефона.

## Управление с телефона

Кнопка **«Телефон»** в верхней панели. Телефон подключается напрямую к компьютеру — промежуточных серверов нет.

1. Нажмите **«Включить доступ»** — появится QR-код и ссылка вида `http://192.168.0.10:17891/m?t=…`.
2. Наведите камеру телефона на код или откройте ссылку в мобильном браузере.
3. Добавьте страницу в закладки: токен и порт постоянные, второй раз сканировать не нужно.

Под QR-кодом — чипы с локальными IP-адресами и «Интернет»: ими выбирается, куда ведёт код, если у компьютера несколько сетевых адресов.

**В окне подключения:**

- **Включать доступ при запуске программы** — доступ поднимается сам вместе с FinMaster.
- **Через интернет (ngrok)** — см. следующий раздел.
- **Токен ngrok**, **Telegram**, **Устройства** — три сворачиваемых блока, чтобы окно не разрасталось.
- **Устройства** показывают подключённые телефоны в реальном времени: заголовок блока и список обновляются сами, пока окно открыто — видно, кто онлайн, с какого адреса и когда заходил последний раз. Любое устройство можно забыть.
- **Копировать ссылку** — отправить её себе любым способом.
- **Новая ссылка** — сбрасывает токен: старые закладки перестают работать, все устройства отключаются. На случай, если ссылка утекла.
- **Выключить доступ** — закрывает сессию. Токены ngrok и Telegram при этом сохраняются, вводить их заново не придётся.

Кнопка `i` в заголовке окна открывает отдельное руководство по подключению.

Всё, что делается на телефоне, сразу видно на компьютере — и наоборот. Переход по разделам тоже зеркалится: открыли на телефоне «Заказы» — на компьютере откроется тот же раздел, открыли конкретный заказ — компьютер перейдёт на дашборд и покажет цифры именно этого заказа.

## Доступ через интернет (ngrok)

Чтобы заходить не только из своей Wi-Fi:

1. Скачайте ngrok с [ngrok.com/download](https://ngrok.com/download), распакуйте и добавьте программу в `PATH`.
2. Зарегистрируйтесь на ngrok.com и скопируйте **Your Authtoken** из кабинета.
3. В окне «Телефон» включите **«Через интернет (ngrok)»**, вставьте токен в блок «Токен ngrok» и нажмите **«Сохранить и включить»**.
4. QR сменится на адрес вида `https://….ngrok-free.app/m?t=…` — его и сохраняйте в закладки телефона.

Нюансы: на бесплатном тарифе адрес меняется после перезапуска — скопируйте ссылку заново (или спросите её у Telegram-бота). При первом открытии ngrok может показать свою страницу-предупреждение — нажмите **Visit Site**. Токен хранится только на этом компьютере и не забывается при выключении тумблера.

## Telegram-бот

Бот присылает актуальную ссылку на телефон — удобно, когда адрес ngrok меняется.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В окне «Телефон» → блок **Telegram** вставьте токен и нажмите **«Запомнить токен»**. Chat id заполнять не обязательно — он подставится, как только вы напишете боту.
3. В Telegram нажмите **/start**.

**Что умеет бот:**

- команды `/start` (меню) и `/link` (получить ссылку), плюс кнопка **«Получить ссылку»** на клавиатуре;
- присылает ссылку кнопкой **«Открыть FinMaster»** — нажатие сразу открывает мобильный интерфейс, ссылка всегда актуальная; рядом кнопка «Обновить ссылку»;
- **явно показывает тип подключения** в начале сообщения: `🌐 ИНТЕРНЕТ` (работает из любой сети) или `📶 ЛОКАЛЬНАЯ СЕТЬ` (только из той же Wi-Fi) — чтобы не гадать, почему ссылка не открывается в метро;
- **предупреждает о выключенных тумблерах**: если доступ с телефона отключён или выключен ngrok, бот не включает их молча, а пишет, что именно нужно включить на компьютере, и просит запросить ссылку снова.

Кнопка **«Отправить ссылку сейчас»** в окне подключения пришлёт ссылку в Telegram, не вставая из-за компьютера.

## Мобильный интерфейс

Открывается по ссылке `/m?t=<токен>`, рассчитан на телефон, поддерживает полноэкранный режим и светлую/тёмную тему. Наверху — отмена, повтор и меню, ниже — строка синхронизации с состоянием связи.

**Четыре вкладки:**

- **Заказы** — поиск, сортировка, чипы-фильтры и список заказов. На карточке — номер и название заказа, суммы и статус. Кнопка `+` создаёт заказ.
- **Сводка** — KPI и выводы по отчёту с тремя рядами фильтров: период, состояние заказов и статусы позиций. Внизу блок **«Кто должен»** — карточки с номером и названием заказа, суммой долга и заказчиком.
- **Снимок** — тот же снимок для заказчика, что и на компьютере: выбор заказа, 4 темы (Бирюза, Золото, Минимал, Ночь), наборы полей, заголовок, скрытие подписей и даты. Результат можно **отправить через «Поделиться»**, сохранить PNG в телефон или скопировать текстом.
- **Отчёты** — текущий файл, кнопка «Сохранить на компьютере», создание нового отчёта, список недавних (открываются на компьютере), «Скопировать постоянную ссылку» и «Отключиться от компьютера».

**Карточка заказа** на телефоне: шапка с номером, заказчиком и названием, список позиций, кнопки «+ Позиция», «Снимок для заказчика», «Дублировать заказ», «Удалить заказ».

**Редактор позиции** — отдельная панель на весь экран со всеми полями строки (тип, продукт, количество, единица, цена, скидка, даты, оплата, статус) и стрелками `‹` `›` для перехода к соседней позиции без закрытия редактора.

**Отмена и повтор** работают с телефона и применяются к документу на компьютере. Изменения летят в обе стороны; если связь пропала, строка синхронизации об этом скажет. Когда страница закрывается, компьютер сразу видит, что устройство отключилось.

## Безопасность

- Доступ с телефона включается вручную и работает, пока открыта программа.
- Ссылка содержит токен сессии; без него запрос с другого адреса отклоняется.
- С телефона доступен **только мобильный интерфейс** — рабочий стол программы через туннель не открывается.
- Токены ngrok и Telegram хранятся в локальном конфиге на этом компьютере и никуда не отправляются, кроме самих сервисов ngrok и Telegram.
- «Новая ссылка» мгновенно обнуляет доступ для всех прежних устройств.

## Где хранятся настройки

Настройки программы: `%APPDATA%\FinMaster\config.json` (на не-Windows — `~/.config/FinMaster/config.json`).

В нём: список недавних файлов, флаг автосохранения, последняя папка, тема и блок `remote` — токен сессии, порт, автозапуск доступа, список запомненных устройств (до 20), настройки ngrok и Telegram.

Тема и список недавних дополнительно кешируются в `localStorage` интерфейса. Сами отчёты лежат там, где вы их сохранили, — программа их не перемещает.

## API для разработчика

Все маршруты локальные. Запросы с чужих адресов проходят только к мобильной части и только с токеном.

| Маршрут | Назначение |
| --- | --- |
| `GET /` | интерфейс компьютера |
| `GET /m` | мобильный интерфейс |
| `GET /api/bootstrap` | стартовые данные: тема, недавние, автосохранение, состояние доступа |
| `POST /api/dirty`, `/api/autosave`, `/api/theme` | состояние документа и настройки |
| `POST /api/dialog/open`, `/dialog/save`, `/dialog/export`, `/dialog/png` | системные диалоги |
| `POST /api/write`, `/write-text`, `/write-bytes` | запись отчёта, текста и PNG |
| `POST /api/open-path`, `/api/recent/remove` | работа со списком недавних |
| `POST /api/clipboard-text`, `/api/clipboard-png` | буфер обмена |
| `POST /api/remote/start`, `/remote/stop` | включение и выключение доступа с телефона |
| `POST /api/remote/address` | выбор адреса для QR-кода |
| `POST /api/remote/ngrok` | тумблер и токен ngrok |
| `POST /api/remote/telegram` | токен бота, chat id, отправка ссылки |
| `POST /api/remote/rotate`, `/remote/forget` | новая ссылка, забыть устройство |
| `GET /api/remote/info` | состояние доступа, список устройств и клиентов |
| `POST /api/remote/publish`, `/remote/push` | обмен документом между компьютером и телефоном |
| `GET /api/remote/pull`, `/remote/session` | получение изменений и данных сессии телефоном |

## Решение проблем

**Телефон не открывает локальную ссылку.** Проверьте, что телефон и компьютер в одной Wi-Fi, и разрешите Python в брандмауэре Windows для частной сети. Если у компьютера несколько адресов, попробуйте другой IP-чип под QR-кодом.

**Ссылка была, а теперь не работает.** Скорее всего адрес ngrok сменился после перезапуска или кто-то нажал «Новая ссылка». Откройте окно «Телефон» и скопируйте актуальную ссылку либо запросите её у бота.

**ngrok не включается.** Программа ngrok должна быть в `PATH`, а токен — вставлен в блок «Токен ngrok». Ошибку подключения окно показывает текстом под кнопкой.

**Бот молчит.** Проверьте токен из @BotFather и что программа запущена. После смены токена напишите боту `/start` заново — chat id подставится сам.

**Бот пишет, что доступ выключен.** Так и задумано: он не включает доступ или ngrok молча. Включите нужные тумблеры в окне «Телефон» и нажмите «Получить ссылку» ещё раз.

**Порт занят.** FinMaster сам подберёт свободный порт и запомнит его — QR-код и ссылка обновятся.

**Интерфейс открылся в браузере, а не в своём окне.** Не установился `pywebview`. Выполните `python -m pip install pywebview`. В браузерном режиме сохранение идёт через скачивание файла.

**Автосохранение не срабатывает.** Отчёт ещё ни разу не сохраняли вручную — программа не знает путь. Сохраните файл один раз, дальше галочка заработает.
