С чего начать

FinMaster — учёт заказов на вашем компьютере. Телефон подключается к нему напрямую, отдельного сервера в интернете нет.

Обычный запуск

  1. Запустите FinMaster.exe. Если рядом ещё нет программы, он спросит папку (по умолчанию D:\Program Files\FinMaster) и скачает файлы.
  2. Две галочки — ярлык на рабочем столе и в меню Пуск — включены. Ярлык открывает FinMaster.exe из папки программы.
  3. Python программа докачивает сама, если своей копии ещё нет. Окно установки Python его не ставит.
  4. Когда всё на месте, открывается окно без чёрной консоли: заставка, затем FinMaster.

Дальше программу удобнее открывать ярлыком или файлом run.vbs в папке программы. run.bat делает то же самое, но при двойном щелчке на мгновение мелькает окно командной строки — это ограничение Windows, не ошибка.

Программа проверялась только в Windows. На других системах работа не гарантируется.

Если программа уже стоит

При запуске программа не спрашивает про обновление. Кнопка справа от «?» светится, если есть версия новее. В вопросе указаны дата новой версии и дата той, что установлена сейчас. Согласие закрывает окно и запускает update.vbs. Если новой версии нет, та же кнопка может заново скачать файлы и заменить повреждённые.

Если exe запущен не из папки программы, но установка уже записана, на выбор: удалить, обновить или восстановить, либо просто запустить.

Где лежит Python

Если рядом с программой есть папка python с pythonw.exe, используется она, и пункт «Среда запуска» в меню логотипа скрыт. Иначе программа открывается копией из Документы\FinMaster\python.

Пункт Среда запуска может переключить следующий запуск на Python, уже установленный в Windows, если он есть. Там же видно, каких библиотек ещё нет. Если системного Python нет, переключателя нет. Выбор системного Python не отменяет свою копию: скачивание нужно, пока своей среды нет.

Первый отчёт

При запуске открывается последний отчёт, если файл ещё на месте. Если недавних нет, на стартовом экране две колонки: все файлы из Документы\FinMaster и недавно открытые. Кнопка «Новый отчёт» создаёт пустой файл.

Дальше имеет смысл пройти разделы слева сверху вниз: заказы, дашборд, касса, календарь. Справка устроена так же.
