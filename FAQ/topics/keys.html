В количестве, цене и скидке заказа можно писать формулу: 2+3*4. Запятая становится точкой: 2,5 → 2.5.

Календарь, облако, хранилище

Календарь: ← → период, в месяце Shift с стрелками — год, T сегодня, 1 2 3 виды, Enter открыть заказ. На таймлайне Ctrl+колесо — масштаб, Shift+колесо — листать дни. Пока открыт словарь, эти клавиши отчёт не трогают.

Облако: / поиск, F показать всё, T автотур по долгам, Enter открыть узел, стрелки — соседний узел.

Хранилище: Ctrl Q пополнение, Ctrl W снятие, Ctrl E копилка.

Калькулятор: Delete удалить ноду, Ctrl D дублировать, Esc отменить линию, Alt+клик снимает связь со входа.

См. также: Ассистент, Поиск по отчёту.
