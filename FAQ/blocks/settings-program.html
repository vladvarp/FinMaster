Настройки

При входе в Windows откроется эта копия программы.

Архив .fms. Python из папки отчётов и модели Vosk выключены, пока галочка не стоит. В подписи видны версия Python, библиотеки и описание модели.

Отдельный файл .fmt: токен ngrok и Telegram вместе с пользователями. В файле токены не читаются как текст, импорт открывается на другом компьютере.
