# FinMaster

Десктоп-программа учёта заказов: Python-сервер (Flask) и HTML-интерфейс в собственном окне (WebView2 на Windows). Всё, что нужно бухгалтеру и финансисту небольшой мастерской или студии: заказы с позициями, оплаты и долги, дашборд, аналитика периодов, платёжный календарь, прогноз выручки на месяцы и годы, календарь работ (когда заказ начали и когда закрыли), калькулятор схем из заказов, **презентация** — инфографика из блоков со значениями из схем, снимки для заказчика и управление с телефона.

Данные лежат в одном файле отчёта `.fmaster` — как книга Excel. Никаких внешних серверов и облаков: программа работает на компьютере, а телефон подключается напрямую к нему.

Программа только для Windows. На других системах она не проверялась, и работа там не гарантируется.

## Быстрый старт

```bat
FinMaster.exe
```

`FinMaster.exe`, если рядом нет `run.vbs`, спрашивает папку (по умолчанию `D:\Program Files\FinMaster`) и скачивает с GitHub только файлы последнего коммита, без истории. Папки и файлы, имя которых начинается с точки, не скачиваются. Запущенный файл `FinMaster.exe` копирует себя в папку программы. Файлы качаются по 40 сразу, при сбое каждый запрашивается до 20 раз. Две галочки, обе включены: ярлык на рабочем столе и ярлык в меню Пуск. Ярлык открывает `FinMaster.exe` из папки программы. Python это окно не ставит: его по-прежнему докачивает сама программа, если своей копии ещё нет. Когда снимок скачан, в папке программы появляется `commit.txt` — дата и время последнего коммита на GitHub. Если этого файла ещё нет, программа сверяет `README.md` в папке с файлом на GitHub: совпали — создаёт `commit.txt`, не совпали — считает версию старой и вместо даты установленной версии пишет, что файлы, вероятно, повреждены. При запуске программа об этом не спрашивает. Кнопка справа от «?» проверяет GitHub при запуске и ещё раз в момент нажатия, до окна. Светится янтарным, если есть версия новее, и красным, если своей даты нет, а файлы в папке не совпали с репозиторием. Нажатие показывает дату новой версии и дату установленной; при красном свечении вместо даты — «Вероятно, есть повреждённые файлы». Согласие закрывает окно и запускает `update.vbs`: скрипт сам, уже установленным Python, скачивает файлы и записывает новое время. Если вышла версия новее и в `commit.txt` нет пометки о нарушенной целостности, качаются только файлы, которых нет или которые отличаются от нового коммита. При нарушенной целостности, при повреждённых файлах без своей даты и когда пользователь скачивает последнюю версию ещё раз — полный снимок, как при установке. Если свечения нет, окно сообщает, что это последняя версия. В правом верхнем углу — «О программе»: копирайт V.Ar Production с годом из commit.txt, лицензия GNU GPL версии 3, ссылки на Telegram и GitHub. Когда даты версий совпадают, в окне есть «Проверить целостность»: файлы программы сверяются с GitHub, и при расхождении в `commit.txt` дописывается пометка, кнопка горит красным с восклицательным знаком, а «i» показывает список отличий. Пока пометка есть, сверка повторяется при запуске и снимает её, когда файлы совпали. Та же «i» есть в окне, когда вышла новая версия. `FinMaster.exe` при этом не запускается. Если exe запущен не из папки программы, но установка записана и `run.vbs` на месте, на выбор: удалить, обновить или восстановить, запустить.

Дальше exe запускается без окна консоли. Он смотрит py-файлы программы и по импортам понимает, какие библиотеки нужны, включая встроенные вроде tkinter для заставки. `requirements.txt` задаёт только версии сторонних пакетов. Если рядом с программой уже есть папка `python` с `pythonw.exe`, exe ничего не скачивает и сразу открывает `run.vbs`. Иначе, если в `Документы\FinMaster\python` уже есть Python и эти библиотеки, exe тоже сразу открывает `run.vbs`, и заставку показывает уже сама программа. Свою заставку exe включает только когда своей копии рядом с программой нет, а в папке отчётов Python ещё нет или не хватает библиотек. Выбор системного Python в настройках это скачивание не отменяет.

Если рядом с программой уже есть папка `python` с `pythonw.exe`, запускается она: ничего не скачивается, а пункт **Среда запуска** в меню логотипа скрыт. Иначе программа открывается копией из `Документы\FinMaster\python`. Пункт **Среда запуска** может переключить следующий запуск на Python, уже установленный в Windows, если он есть. Там же видно, какие библиотеки стоят, а каких ещё нет. Если системного Python нет, переключателя нет.

`run.vbs` (или `launch.vbs`) по-прежнему открывает окно без консоли: заставка, затем FinMaster. Сам Python он не скачивает — для первого компьютера без среды нужен `FinMaster.exe`. При таком запуске, если записи ещё нет, программа добавляет себя в «Приложения» Windows. Удаление — `uninstall.vbs` в папке программы или пункт в «Приложениях»: по умолчанию снимаются папка программы (ярлыки, привязка `.fmaster` и `.fbak`, автозагрузка) и Python в `Документы\FinMaster\python`. Папка с `.git` — репозиторий, она не удаляется. Папка настроек `%APPDATA%\FinMaster`, история, резервные копии и сами отчёты `.fmaster` остаются, пока их галочки не включены; эти четыре пункта уходят в корзину.

Файл `run.bat` делает то же самое, но при **двойном щелчке** Windows на мгновение показывает окно `cmd` — это ограничение `.bat`, не программы. Из уже открытого терминала `run.bat` консоль не мигает.

Или вручную:

```powershell
python -m pip install -r requirements.txt
python launch.py
```

Для отладки с консолью задайте `FINMASTER_CONSOLE=1` и запустите `python launch.py` или `python app.py`.

Откроется отдельное окно FinMaster, а не вкладка системного браузера. Если пакет `pywebview` недоступен, программа откроет интерфейс в обычном браузере — тогда сохранение файла идёт через скачивание, а системные диалоги выбора файла недоступны.

Зависимости: `flask>=3.0.0`, `pywebview>=5.0`.

## Как это устроено

- **`FinMaster.exe`** / **`starter.py`** — вход без консоли. Если рядом нет `run.vbs`, скачивает снимок с GitHub в выбранную папку и копирует себя. Если `run.vbs` уже рядом — окно открывается без вопроса об обновлении. Кнопка справа от «?» светится, если есть версия новее, и в вопросе показывает обе даты. Если GitHub не ответил, дата установленной берётся из commit.txt. Скачивание делает `update.vbs`. Затем список библиотек из импортов в py-файлах, не только из `requirements.txt`. Если рядом с программой есть `python\pythonw.exe`, сразу открывает `run.vbs` и ничего не скачивает. Если Python и библиотеки уже лежат в `Документы\FinMaster\python`, тоже сразу открывает `run.vbs` с заставкой программы. Иначе на своей заставке докачивает их в папку отчётов, и только потом запускает `run.vbs`. Системный Python в настройках скачивание не отменяет.
- **`launch.py`** / **`launch.vbs`** / **`run.vbs`** / **`bootstrap_python.ps1`** — само окно: без консоли, заставка, проверка библиотек и вызов `app.py`. Скрипт установки пишет Python в `Документы\FinMaster\python` и не открывает чёрное окно. `launch.vbs` перед стартом записывает программу в «Приложения», если её там ещё нет.
- **`uninstall.vbs`** — удаление с галочками. Папка программы (ярлыки, привязка иконок `.fmaster` и `.fbak`, автозагрузка) и Python в папке отчётов включены. Папка репозитория (есть `.git`) не удаляется. Папка настроек `%APPDATA%\FinMaster` (в ней `config.json`), история, резервные копии и отчёты `.fmaster` выключены и при включении уходят в корзину.
- **`app.py`** — Flask-сервер: раздаёт интерфейс, отвечает на API-запросы, работает с файлами и диалогами Windows, поднимает окно pywebview и (по желанию) удалённый доступ.
- **`frontend/`** — интерфейс. Страницы грузят `/app.js`, `/styles.css`, `/mobile.js`, `/mobile.css` и скрипты модулей. `app/`, `mobile/` и папки стилей на диске разрезаны на части `01-`, `02-`, … сервер склеивает их по номерам. `modules/` — уже целые файлы: графики, облако заказов, калькулятор, презентация, PDF, хранилище и календарь дат. `index.html` и `app/` — компьютер. `mobile.html` и `mobile/` — телефон. Значки окна и вкладки — только `favicon.ico`, `favicon.png` и `favicon.svg` в этой папке.
- **`backend/`** — модули: документ и нормализация (`document.py`), настройки, папка отчётов и корзина (`storage.py`), суммы заказа с учётом налогов и затрат (`finance.py`), резервные копии отчётов (`backup.py`), снимки для бота (`snapshot.py`), заставка запуска (`splash.py`), системные диалоги (`dialogs.py`), буфер обмена (`clipboard.py`), генерация QR (`qr.py`), сессия телефона (`remote.py`), ngrok-туннель (`tunnel.py`), Telegram-бот (`telegram.py`), автозагрузка Windows (`startup.py`), установка и обновление с GitHub (`setup.py`), одна копия программы (`instance.py`), привязка `.fmaster` и `.fbak` (`filetype.py`).

Сервер слушает всю локальную сеть (`0.0.0.0`), но запросы с других адресов пускает только к мобильному интерфейсу и только с правильным токеном сессии. Порт по умолчанию **17891**; если занят, программа сама берёт следующий свободный из 12 соседних, а в крайнем случае — любой свободный, и запоминает его.

## Файлы отчётов

Каждый отчёт — файл `.fmaster` (внутри обычный JSON). В нём лежат заказы с позициями, справочники, заказчики и настройки интерфейса (ширина столбцов, тема снимка, срок оплаты, горизонт прогноза, набор кривых на графиках, блюпринты калькулятора, страницы и блоки презентации).

- **Новый отчёт** — `Ctrl+N` или пункт «Новый» в меню логотипа FinMaster.
- **Открыть** — `Ctrl+O`, пункт «Открыть» в том же меню, строка в папке FinMaster или в списке недавних на стартовом экране (то же самое во вкладке «Отчёты» на телефоне). Двойной щелчок по `.fmaster` в проводнике тоже открывает файл в `FinMaster.exe`. Резервная копия `.fbak` открывается так же, но только для просмотра: править её нельзя, пока она не сохранена как новый отчёт. Если перед копией был открыт обычный отчёт, полоса просмотра даёт «Вернуться к отчёту». При запуске программа сама привязывает оба расширения и ставит иконки: у отчёта лист с круговой диаграммой (`frontend/report.ico`), у копии — лист с часами (`frontend/backup.ico`). Если окно уже открыто, вторая копия не стартует: файл передаётся в него. Когда в текущем отчёте есть несохранённые правки, программа сначала спрашивает, сохранять ли их.
- **Сохранить** — `Ctrl+S`, **Сохранить как** — `Ctrl+Shift+S`. Те же команды — в меню логотипа.
- **Автосохранение** — галочка в **настройках отчёта** (шестерёнка у названия). Работает только после первой ручной записи на диск: программе нужно знать путь к файлу. Если автосохранение выключено, при закрытии правки сами на диск не пишутся — программа спросит, сохранить или нет.
- При закрытии с несохранёнными изменениями (и выключенным автосохранением) программа предложит сохранить, отбросить или отменить.
- Список недавних хранит до 15 файлов; лишние строки можно убрать крестиком — сам файл при этом не трогается. Открытая резервная копия `.fbak` в этот список не попадает.

**Папка FinMaster** — `Документы\FinMaster` (создаётся сама). На стартовом экране компьютера и во вкладке «Отчёты» на телефоне виден один и тот же список файлов `.fmaster` из этой папки. Если отчёт создали, скопировали или удалили в проводнике, список на компьютере и на телефоне обновляется сам. Кнопка «Открыть папку» показывает каталог в проводнике.

**Удаление отчёта** из папки FinMaster (крестик на компьютере или «Удалить» на телефоне) отправляет файл в **корзину Windows**, а не стирает его навсегда. Список на обоих устройствах обновляется сразу. Восстановить файл можно из корзины обычным способом.

Запись на диск атомарная: файл сначала пишется во временный, потом подменяет старый — питание пропало, отчёт не потерялся.

## Интерфейс

**Стартовый экран** — при запуске сам открывается последний отчёт из недавних, если файл ещё на месте. Иначе две колонки: все отчёты из папки `Документы\FinMaster` и недавно открытые файлы. Переключатель **Список / Галактики** меняет вид: список как раньше или карта, где каждый отчёт — отдельная галактика (размер по объёму файла, разные типы спиралей). Состояние переключателя запоминается. На карте один клик открывает отчёт. Кнопки «Новый отчёт», «Открыть файл», «Телефон» и переключатель темы. Список папки обновляется сразу, если отчёт создали, скопировали или удалили в проводнике или с телефона. Если открытый файл пропал из папки, программа оставляет его в памяти и предупреждает.

**Боковая панель** — клик по логотипу FinMaster открывает меню файла: Новый, Открыть, Сохранить, Сохранить как, затем тумблер **Автозагрузка** (при входе в Windows запускается `FinMaster.exe`; запись в реестре текущего пользователя) и пункт **Среда запуска**, если он нужен. Иконка логотипа — `frontend/favicon.svg`. Ниже блок «Текущий отчёт»: справа от надписи — **точка несохранённых изменений**; ниже название (его можно править) и слева от него **шестерёнка настроек отчёта** (путь к файлу, автосохранение, валюта ₽ $ € ₸ ₴ £ и точность сумм — от целых до 4 знаков после запятой; те же валюта и точность на телефоне во вкладке «Отчёты»). Если автосохранение включено, в файл уходят и правки с компьютера, и с телефона. Дальше навигация по разделам. Панель сворачивается кнопкой с иконкой панели — остаются иконки разделов и логотип.

**Верхняя панель** — поиск по отчёту, отмена, часы истории снимков и повтор, кнопка «Телефон», переключатель темы, возврат к списку отчётов, экспорт CSV, полный экран окна (`F11`), кнопка с клавиатурой (горячие клавиши, `F1`) и кнопка `?` — полная справка в отдельном окне.

**Темы** — светлая и тёмная, переключаются в любом месте программы и запоминаются между запусками. Тёмная тема применяется и к мобильному интерфейсу.

**Выбор даты** — во всех полях дат на компьютере открывается свой календарь в стиле программы вместо системного окна Windows. Над ним переключатель «Месяц», «3 мес», «6 мес» и «Год»: сразу квартал, полгода или весь год, листание идёт тем же шагом. Клик по названию месяца — сетка месяцев, по году — сетка лет (по 12 на странице), поэтому дата двухлетней давности выбирается в три-четыре клика. Внизу — выбранная дата, «Сегодня» и «Очистить». С клавиатуры: стрелки — день/неделя, PageUp/PageDown — месяц (с Shift — год), Enter — выбрать, Esc — закрыть, Alt+↓ или F4 — открыть; дату можно и просто впечатать в поле. Колесо мыши над календарём листает месяцы, кварталы, полугодия или годы — как выбран вид. На телефоне остаётся системный выбор даты.

**Поиск (`Ctrl+F`)** ищет по номеру заказа, заказчику, названию и продукту, сразу фильтруя список заказов.

**Тосты** — короткие уведомления внизу экрана. У разрушающих действий (удаление заказа, строки, заказчика) в тосте есть кнопка «Отменить».

## Раздел «Заказы»

Главный рабочий раздел. Заказ — это карточка с общими полями и таблицей позиций.

**Шапка заказа:** номер, заказчик (с подсказками из справочника), название. Кнопка `i` открывает заметки к заказу; если заметка есть, кнопка подсвечивается. У каждой позиции в конце строки перед кнопкой `i` стоит галочка: серая, пока у позиции в календаре нет конца, голубая — если закрыта сегодня, зелёная — если раньше (подсказка: сколько дней назад, а если больше 30 — дата закрытия), оранжевая — когда конец позже сегодня. Такая же галочка в шапке таблицы ставит или снимает завершение сразу у всех позиций. Нажатие ставит конец на сегодня и в календаре отмечает позицию завершённой; повторное снимает конец и возвращает её в работу. Кнопка `i` по-прежнему открывает комментарий к строке и подсвечивается, если комментарий есть.

**Срок работ:** начало и конец на карточке заказа. Пустой конец — нет дедлайна, заказ просто идёт. Конец на карточке можно менять, только пока заказа нет в календаре. Как только заказ стоит в календаре, конец берётся из позиций: если хотя бы одна ещё в работе, конечной даты нет; если конец есть у всех, линия заказа заканчивается на самой поздней из них, и раньше этой даты конец заказа не ставится. Кнопки «Начать сегодня» / «Закончить сегодня» ставят дату одним нажатием, пока заказ ещё не в календаре. Статус работ считается сам: без дат, запланирован, идёт сейчас, завершён (конец сегодня или раньше) или снят (все позиции отменены).

**Общие поля заказа** применяются сразу ко всем позициям: скидка %, статус, тип заказа, дата заказа, дата оплаты. Удобно, когда заказ оплатили целиком или сдвинули срок.

**Кнопка «Оплатить все типы»** записывает в каждую строку её итог и сегодняшнюю дату оплаты и, если оплата покрывает сумму, ставит статус «оплачено».

**Таблица позиций** — столбцы: тип заказа, продукт, количество, единица, цена, скидка %, дата заказа, оплачено, дата оплаты, не оплачено, итог, статус. Даты — календарный день без времени. Итог, «не оплачено» и проценты считаются на лету. Позиции с «расходным» типом живут в отдельном блоке под таблицей — см. [Налоги и затраты](#налоги-и-затраты).

- Строки перетаскиваются мышью за левую ручку, порядок сохраняется в файле.
- Ширина любого столбца тянется за границу заголовка и запоминается в отчёте.
- В количестве, цене и скидке работают **формулы**: `2+3*4`, `1200/3`, `(5+2)*100`. Вместо `*` можно писать `x` или `×` (`3x250`), запятая сама превращается в точку. В ячейке остаётся формула, в итогах — результат.
- Кнопки в строке: галочка завершения, комментарий (`i`), дублировать (`⧉`) и удалить (`✕`). Правый клик по ручке перетаскивания открывает меню **«Заморозить позицию»**: строка уходит в блок **«Замороженные позиции»** (он появляется, только если есть хотя бы одна такая), значения сохраняются, но никуда не считаются — не в итоги заказа, не в дашборд, кассу, календарь, облако, снимок и CSV. Так можно спрятать позицию на потом, не удаляя её и не вводя заново. Тем же меню позицию возвращают в заказ.

**Фильтр** в тулбаре — кнопка с воронкой, как в календаре: Все, С долгом, Оплаченные, Этот месяц, Без цены — с количеством заказов в каждой группе. Рядом **«Позиции»** режет уже строки внутри заказов: статус, тип, продукт, единица, заказчик, оплата, скидка и вид строки (доход, расход, замороженные). В одной группе можно отметить несколько значений — подойдёт любое; разные группы сужают список вместе. Переключатель «Исключение» прячет строки, которые подходят под отмеченное. Дата заказа и сумма задаются интервалом, строка поиска в окне находит нужный чип. Заказ без подходящих строк скрывается, в карточке остаются только они, итог считается по ним. «Сбросить» возвращает все строки. При прокрутке списка эта верхняя панель остаётся сверху.

**Сортировка:** сначала новые / старые (по датам позиций), недавно / давно созданные (по фактической дате и времени создания заказа), по номеру, по заказчику, по сумме ↓. Кнопка «+» добавляет заказ и прокручивает список к нему, даже если он не наверху. Справа в тулбаре — живая сводка: число заказов в текущем фильтре, сумма к оплате и долг; она обновляется при правке позиций без перезагрузки списка.

**Действия с заказом:** «Снимок» (картинка для заказчика), «Дублировать» (новый заказ с тем же номером и « - копия» в конце названия; список прокручивается к копии), «Удалить». Кнопка «Снимок заказов» в тулбаре собирает снимок сразу по нескольким заказам.

## Раздел «Дашборд»

**KPI-плитки:** количество заказов и позиций, сумма к оплате после скидок (и отдельно — без отменённых), оплачено с процентом сбора, не оплачено. Считаются по видимому диапазону графика «Выручка по дням». По умолчанию включено «Всё» — весь отчёт.

**Инсайты** — восемь готовых выводов: выручка за месяц со сравнением с прошлым, прогноз до конца месяца по текущему темпу, средний чек, собираемость оплат, лучший заказчик, хит продаж, долги старше 30 дней и количество заказов за 30 дней против предыдущих 30. У метрик со сравнением есть чип тренда `+12%` / `−8%`. Берутся из того же диапазона, что и график.

**Графики:** выручка по дням (по умолчанию «Всё»; кнопки «Всё», «Год», «6 мес», «3 мес», «Месяц», «2 нед» и «Период» — см. «Масштаб графиков» ниже) — несколько кривых (выручка, оплачено, долг, расход, чистыми), ряды включаются чипами в легенде; набор кривых у этого графика свой и запоминается. Клик по точке открывает окно с позициями этого дня: заказы, суммы и долг. Рядом — распределение сумм по статусам за тот же диапазон, цвета берутся из справочника статусов.

**«Требуют внимания»** — позиции с долгом и заказы из чёрного списка. **«Последние заказы»** — быстрый переход к свежим заказам. Оба списка следуют диапазону графика.

**Фокус заказа с телефона.** Когда с телефона открывают конкретный заказ, наверху дашборда появляется блок «с телефона» с цифрами именно этого заказа: кнопка «Открыть в заказах» ведёт к карточке, «Весь отчёт» возвращает общие показатели.

## Раздел «Аналитика»

**Фильтры мониторинга:** дата с/по (календарный день, без времени), поле даты (дата заказа или дата оплаты), группировка (дни, недели, месяцы), статус, тип заказа, заказчик, продукт, единица измерения, сумма от/до, галочка «Только долги». Пресеты периода: Сегодня, 7 дней, Этот месяц, Этот год. Кнопка «Сбросить» возвращает всё в исходное.

**Сравнение периодов A и B** — два независимых интервала с итогами по каждому и графиком сравнения метрик (каждая метрика в своей шкале, чтобы выручка не «съедала» количество заказов).

**График «Динамика»** строится по выбранной группировке. Те же ряды, что на дашборде: выручка, оплачено, долг, расход и чистыми; клик по легенде скрывает или показывает кривую. Выбор рядов у динамики свой и тоже запоминается.

**Масштаб графиков** «Выручка по дням» и «Динамика» — как в хранилище: колесо мыши приближает и отдаляет вокруг курсора, перетаскивание сдвигает приближенный участок, двойной клик показывает всё. Над графиком — быстрые кнопки (дашборд: «Всё», «Год», «6 мес», «3 мес», «Месяц», «2 нед» и «Период»; аналитика: «Всё», «Год», «3 мес», «Месяц»; отсчёт от последней даты), видимый диапазон и число точек. «Период» открывает календарь с тем же переключателем «Месяц», «3 мес», «6 мес» и «Год»: первый клик — начало, второй — конец, промежуток подсвечивается ещё при наведении. Листать можно только окна, где на графике есть дни, и выбрать можно только такие дни. Шкала подстраивается под видимый участок. На дашборде плитки, инсайты, круговая диаграмма и оба списка ниже пересчитываются по этому же отрезку, в том числе после колеса, перетаскивания и своего периода. Панель масштаба появляется, когда точек больше трёх.

**Таблица «Найденные позиции»** — все строки отчёта, попавшие под фильтры, с итогами по ним.

## Раздел «Касса»

Платёжный календарь и работа с дебиторкой — раздел о том, *когда* придут деньги, а не только сколько их всего.

**Настройки сверху:** срок оплаты в днях от даты заказа (0–365, по умолчанию 14) и горизонт прогноза (14, 30, 60 или 90 дней). Оба параметра хранятся в файле отчёта. Кнопка «Копировать сводку» кладёт в буфер текстовую выжимку по кассе — удобно отправить руководителю.

**KPI:** поступит за 7 дней (и за 30), просрочено с максимальной задержкой, средний фактический срок оплаты против договорного, вся дебиторка с процентом собираемости.

**Прогноз поступлений** — накопительный график с двумя линиями: план по сроку оплаты и реалистичный прогноз с учётом платёжной дисциплины заказчиков (насколько каждый из них исторически задерживает оплату).

**Долг по заказчикам** — круговая диаграмма, крупные должники отдельно, остальные в «Прочие».

**Платёжный календарь** — плитки по дням с суммами ожидаемых поступлений. Клик по дню фильтрует реестр дебиторки, повторный клик снимает фильтр.

**Старение дебиторки** — полоса и разбивка долга по корзинам: срок не наступил, просрочка 1–7 дней, 8–30, 31–60, больше 60 дней и отдельно позиции без дат. Под таблицей считается «безнадёжная зона» — доля долга с просрочкой больше 30 дней. Клик по корзине фильтрует реестр.

**Реестр дебиторки** — список неоплаченных позиций с ожидаемой датой, суммой и просрочкой. Действия в строке: отметить оплату одной кнопкой, скопировать готовый текст напоминания заказчику, открыть заказ, отфильтровать реестр по этому заказчику.

**«Кто должен»** — таблица по заказчикам: долг, число позиций, дисциплина (средняя задержка оплаты относительно срока).

## Раздел «Прогнозирование»

Вкладка сразу под «Кассой». Считает, какой будет выручка, оплаты, затраты и сумма чистыми на 6 месяцев, год, 2, 3 и 5 лет. Ряд берётся из дат позиций текущего отчёта: пустые месяцы между первой и последней полной датой считаются нулями, незаконченный текущий месяц в обучение не входит.

Прогноз — медиана нескольких моделей, которые на коротких месячных рядах обгоняют одну формулу и не требуют скачивания нейросетей: наивный и сезонный наивный, дрейф, экспоненциальное сглаживание, затухающий тренд Хольта, Тета и Тета с сезоном, Хольт–Уинтерс. Модели с плохой проверкой на последних месяцах в медиану не попадают. По умолчанию на графике ансамбль и коридор: разброс моделей плюс обычный 80-процентный запас по ошибке. Кнопки над графиком и строки таблицы переключают отдельную модель. Рядом суммы по календарным годам и ошибка каждой модели (sMAPE).

## Раздел «Календарь»

Производственный календарь — когда заказы **начаты**, **идут сейчас** и **закрыты**. Это не касса: там про деньги, здесь про ход работ в цеху.

Вкладка стоит в боковом меню сразу под «Прогнозированием». На карточке заказа те же даты начала и конца; календарь собирает их в три вида:

- **Таймлайн** — диаграмма Ганта выбранного отрезка дней. Сверху полоска периода по текущему фильтру: заказы линиями (как дорожка в Adobe Audition), рамка показывает, что видно сейчас. Полоски в навигаторе занимают свободную строку, если по датам не пересекаются; новая строка появляется только при наложении. Позиции заказа раскрываются стрелкой слева или правым кликом по строке заказа (правый клик по строке позиции сворачивает их обратно). Если раскрыть позиции заказа, дорожка подрастает и показывает их полоски: по умолчанию от даты заказа позиции до конца срока заказа, раньше даты заказа полоску не протянуть. За крайними заказами слева и справа запас около месяца. При первом открытии сегодня у правого края: после него в кадре ещё два дня. Края рамки меняют масштаб. Ctrl+колесо над таймлайном меняет масштаб вокруг курсора, Shift+колесо листает дни по горизонтали. Колесо без клавиш над полоской навигатора тоже меняет масштаб, над линейкой дней — листает период. Наведение на линейку дней подсвечивает столбец на всю высоту списка и показывает дату целиком (день недели, день месяц год; у выходного есть пометка). Пока тянете полосу или её край, дата висит рядом с курсором, столбец дня подсвечивается по всей высоте списка, длина линии меняется сразу, не после отпускания кнопки. Строки сверху вниз: сначала заказы в работе, затем более свежие даты — старые закрытые не всплывают наверх. Если конец работ позже сегодня, это дедлайн: золотой блик и ромб на правом краю полосы, в подписи «до …». Пустой конец — дедлайна нет, заказ просто идёт, это не просрочка. Заказ выбирают кликом по полосе, по названию слева или по пустому месту строки. Полоса заказа тянется мышью (сдвиг целиком), края меняют старт и финиш — на полосах нет подписей, номер и название стоят слева. Стрелка слева от названия раскрывает **позиции** заказа: у каждой своя полоса вдвое тоньше полосы заказа. Цвет полосы задаётся в окне «Цвета календаря» (см. ниже): по умолчанию оплаченная зелёная, с долгом — оранжевая вуаль поверх полосы, завершённый заказ с долгом — красная, **запланированная** (срок целиком в будущем) — голубая. Та же логика у полосы самого заказа, только она толще. У позиции, которая идёт сейчас, отдельный цвет «Выполняется»: он не подменяет «В работе» у полосы заказа. Пока срок позиции не трогали, она длится как заказ; после правки остаётся своей. Если у заказа **нет даты конца**, позицию можно увести дальше сегодняшнего дня: полоса заказа удлинится со стрелкой «ещё идёт», сам заказ без конца остаётся, а будущая позиция рисуется как запланированная. Если у заказа нет конца, но конец есть у каждой позиции, линия заказа принимает самую позднюю из этих дат — раньше неё конец заказа выбрать нельзя. Пока хотя бы одна позиция в работе, у заказа конечной даты нет. Конец позиции может уйти дальше прежнего конца заказа: линия заказа подтянется. Кнопка «Как у заказа» в правой панели возвращает наследование. Выходной не рвёт полосу заказа и позицию: столбец только отмечен как выходной, линия идёт сквозь него. Если в этот день нет ни одной активной позиции, полоса заказа штрихуется как пауза. Пауза по-прежнему оставляет в полосе разрыв. **Паузы** правят только у позиций (Shift+клик по полосе позиции или «Пауза в этот день» справа при выбранной позиции). У полосы заказа паузы **не ставят вручную**: день на заказе штрихуется сам, если в сроке нет ни одной активной позиции или все покрывающие позиции в этот день на паузе. Такие паузы заказа только для вида — тянуть их нельзя; чтобы изменить, правят позиции. Срок заказа (начало и конец) не сжимается: паузы — дырки внутри. Если у заказа нет даты конца и пауза позиций доведена до сегодня, на заказе она остаётся открытой и на новые дни, пока позиции не снимут. Такие заказы в таймлайне помечены «На паузе» у названия и на полосах. В неделе и месяце они скрыты, пока включена кнопка «скрывать на паузе». Сегодняшняя дата — красная линия через шапку и все строки, выходные, выбранный день и дни с перегрузом подсвечены тем же столбцом на всю высоту.
- **Классический** — сетка месяца с понедельника. Месяц и год выбираются в заголовке, стрелки ‹ › листают месяцы. В ячейке видны заказы этого дня и сколько их всего. Статус заказа — только иконка: **старт**, **финиш**, **старт и финиш** (если уложились в один день), **пауза**, **выполнялось** (прошедший день), **выполняется** (сегодня), **запланировано** (день после сегодня). Слово статуса видно по наведению. День после сегодня показывает позицию только там, где на таймлайне есть её полоса. Закрытый заказ на завтра не попадает. Позиция без даты конца, которая сегодня идёт и не на паузе, видна ещё на завтра, если у заказа тоже нет конца и Shift не поставил паузу. Кнопка скрытия пауз прячет и будущую паузу. Клик по дню выбирает его для быстрой постановки старта/финиша выбранному заказу и чтобы сделать день выходным или рабочим точечно.
- **Неделя** — семь колонок с понедельника: старт, середина, пауза и финиш, плюс полоска загрузки дня. Середина прошедшего дня — «Выполнялось», сегодняшнего — «Выполняется», будущего — «Запланировано». У позиции те же слова по её собственному сроку. На завтра попадают только позиции, у которых таймлайн рисует полосу в этот день. Уже закрытые заказы туда не ставятся. Позиция без даты конца, которая сегодня идёт и не на паузе, стоит ещё на завтра, если у заказа тоже нет конца и Shift не включил паузу. Кнопка скрытия пауз прячет паузу и в будущем.

**Сводка:** плитки больше не занимают строку. Справа от «Плана работ» круглая кнопка **i** — при наведении видно, сколько заказов идёт сейчас (пустой конец — нет дедлайна, это не просрочка), сколько стартов и финишей на текущей неделе, сколько ещё без дат, пик одновременной загрузки.

**Фильтры и вид:** слева кнопка с воронкой (все / идёт сейчас / запланированы / завершены / без дат), рядом иконки видов: таймлайн (полоски Ганта), классический (сетка месяца), неделя (столбики дней). Глобально отмечают дни недели (по умолчанию сб и вс). Точечно — клик по дню и справа «Сделать выходным» или «Сделать рабочим»; такие дни на доске фиолетовые, обычные выходные — красные. На выбранный день можно оставить заметку. Выходные и вид пишутся в файл отчёта. Строка поиска сверху тоже режет календарь. Справа на той же строке — период: ‹ › и название диапазона, затем иконки «сегодня», «к выделенному дню», тумблер «переход к началу заказа», тумблер «скрывать на паузе» (две полоски; только неделя и месяц, в таймлайне кнопки нет; та же кнопка на телефоне), цвета (палитра), выходных (домик в календаре), плана работ (лист) и сводки (**i**). «К выделенному дню» делает то же, что «сегодня», но для дня, который обведён сейчас. Тумблер перехода по умолчанию включён и запоминается между запусками отдельно от файла отчёта: пока он включён, выбор заказа переносит календарь к началу работ; если выключить — выбор заказа календарь не сдвигает. Тумблер «скрывать на паузе» тоже включён по умолчанию и запоминается так же: в неделе и месяце прячет заказы и позиции со статусом «На паузе» (и блок «На паузе» справа). Повторное нажатие возвращает их. На телефоне эта кнопка включает то же самое: переключили здесь — переключилось там. В таймлайне кнопки нет, паузы там видны как раньше. Повторный клик по уже выделенному заказу снимает выделение.

**Цвета:** кнопка-палитра в строке периода открывает окно «Цвета календаря». Оно остаётся, пока его не закроют крестиком: клик снаружи, другие меню и повторное нажатие кнопки его не прячут. За заголовок окно перетаскивают. Вкладки «Светлая» и «Тёмная» хранят схему каждая для своей темы программы; на доске сразу видна схема текущей темы. Два блока, у названия кружок **i** с подсказкой.

**Линии** красят полосы заказов и позиций. «Оплачено» — закрытая оплатой полоса. «Долг» — полупрозрачная вуаль только поверх рабочей полосы, штрих паузы она не закрашивает. «Закрыт с долгом» — заказ уже завершён, а долг остался. «Запланировано» — срок ещё впереди. «В работе» — полоса заказа, который идёт, и полосы позиций, которые не отмечены отдельно как «идёт сейчас». «Выполняется» — только позиция, которая идёт сейчас: её полоса на таймлайне и цветная полоска слева на неделе. «Завершено» — закрытая позиция. «Штрих паузы» — свой цвет штриховки паузы.

**Статусы** красят слова, не полосы: «Старт и финиш», «Выполняется», «Выполнялось», «План» и «Пауза». Это подписи под названием в таймлайне и роли дня на неделе и в месяце. Слово «Выполняется» в статусах и цвет полосы «Выполняется» в линиях — разные настройки.

У каждого цвета есть прозрачность. Цвет выбирают без системного окна Windows: поле тона и яркости, полоска оттенка, ползунок прозрачности, поле hex и сетка образцов. У «Долга» прозрачность по умолчанию ниже, чем у остальных цветов, у штриха паузы тоже. Встроенных профилей девять: Текущая, Море, Лес, Закат, Чернила, Ягода, Песок, Север, Контраст. Свой профиль сохраняют по имени; «Обновить» перезаписывает выбранный свой, крестик у имени удаляет. Профиль включается для темы, открытой во вкладке окна. «Вернуть» снимает правки, которые ещё не записаны в профиль. Схемы общие для всех отчётов и переживают перезапуск.

Доска таймлайна и правая панель занимают высоту окна программы; если заказов или текста больше, список крутится колесом. Навигатор периода и линейка дат остаются сверху, короткая подсказка — внизу, строки Ганта уезжают под линейку дат.

**Правая панель:** выбранный заказ или позиция (даты; у позиции — комментарий и список пауз со «Снять», у заказа паузы только для справки «из позиций»; начать/закончить сегодня, сдвиг на день, подставить крайние даты позиций или вернуть позицию «Как у заказа», снять даты, открыть карточку), выбранный день (выходной/рабочий, заметка, старт/финиш выбранного, пауза в этот день — только если выбрана позиция), список «в работе» и заказы без дат. Клик по заказу в панели переносит календарь к его началу, пока включён тумблер «переход к началу заказа». Кнопка «Подставить даты с позиций всем без дат» заполняет пустые сроки по датам строк заказа. «План работ» копирует текстовую сводку периода в буфер — удобно отправить в чат смены. Отмена (`Ctrl+Z`) откатывает правки дат, пауз, выходных и заметок.

Двойной клик по заказу открывает карточку. Вид, фильтр и выходные запоминаются в файле отчёта. Клавиши в разделе: `←` `→` период, `T` сегодня, `1`/`2`/`3` виды, `Enter` открыть выбранный. В таймлайне Ctrl+колесо меняет масштаб, Shift+колесо листает дни по горизонтали, колесо без клавиш над строками прокручивает список.

## Раздел «Калькулятор»

Нодовый калькулятор стоит в боковом меню сразу под «Календарём». На телефоне раздела нет: схемы собирают только на компьютере.

Слева меню заказов — оттуда заказ перетаскивают на поле (или кликают), и появляется нода со **всеми позициями** (доход, налог, затрата и замороженные). У каждой позиции свой выход с суммой, плюс общий «Итого». Цвета портов разные: доход — бирюзовый, налог — янтарный, затрата — розовый, замороженные — серые. Кнопка **Σ** в шапке ноды открывает меню типов позиций: можно вывести выход **суммы всех позиций одного типа** (подписи вида `Σ Производство`).

**Правый клик** по выходу позиции или по сумме типа открывает меню доп. полей; они появляются как дочерние выходы под этой строкой и пропадают, когда связь с ними снимают:

- обычная и замороженная доходная позиция — количество, цена, скидка, оплачено, не оплачено;
- налог со своей суммой и затрата — количество, сумма за единицу;
- налог процентом (% от выручки / % от выручки − затраты) — процент;
- сумма типа — те же поля, что у позиций этого типа, но **сложенные** по всем таким строкам.

Рядом в том же меню ноды-инструменты и список других блюпринтов. Блоки **Ноды**, **Схемы** и **Заказы** сворачиваются кликом по заголовку (по умолчанию раскрыты):

- **Оператор** — четыре кнопки `+ − × ÷`, экран с результатом и один выход. Входов сначала два, максимум двадцать: следующий пустой вход появляется, только когда занят последний видимый.
- **Формула** — входы и выходы добавляет сам пользователь. И входы, и имя после `=` — только одна заглавная латинская буква (**A**…**Z**), без повторов в пределах ноды. В выражении те же буквы: строчная латинская сама становится заглавной, другие буквы не вводятся. По умолчанию входы **A** и **B**, выходы **C** и **D**: `A+B=C` и `(-40+A)*B=D`. Выходы считаются сверху вниз: результат верхнего можно использовать в нижнем (например `A+B=L`, затем `L*2=M`). Повтор буквы или ошибка в выражении красит ноду и обводит красным именно это поле. Справа на ноде ручка ширины. Сверху ноды — выпадающий список профилей: пока профилей нет, список неактивен и предлагает создать новый. Выбор подставляет сохранённые входы, выходы и формулы (связи этой ноды при этом снимаются). Если после выбора что-то в ноде изменить, список становится пустым. «+» открывает окно с названием и сохраняет текущую схему; крестик открывает список профилей, удаление только после подтверждения. Профили общие для всех отчётов и не пропадают после перезапуска.
- **Процент** — два входа: число и `%`, выход `число × % / 100`.
- **Константа** — пользовательское число и один выход. Под числом — поле комментария (до 500 символов, можно в несколько строк): что это за число и откуда оно. Комментарий сохраняется в файле и виден в подсказке замка, если константа задаёт поле заказа.
- **Результат** — экран как у оператора: показывает значение пришедшей связи, без арифметики. Имя, счётчик приоритета (меньше — выше) и глазик (скрывает выход из ноды схемы) в шапке. Можно протянуть дальше через выход. Видимые ноды «Результат» на схеме становятся выходами **ноды этой схемы**, когда её ставят на другой блюпринт — в порядке приоритета. В меню нод «Результат» стоит перед «Группой».
- **Фильтр** — без входных портов: заказчик, заказ, период, фильтр оплаты, тип, продукт и статус прямо на ноде (у всех, кроме периода, можно выбрать несколько значений). Если выбрано больше одного пункта, справа появляется × — сбрасывает выбор. Длинный список в выпадающем окне крутится колесом без зума схемы; после клика по пункту прокрутка списка не сбрасывается. Продукты в списке без дублей по регистру и пробелам. Выходы — сводка по срезу (заказы, позиции, к оплате, оплачено, долг, расходы, чистыми).
- **Дашборд** — тоже без входов, те же встроенные фильтры и поведение мультивыбора. По умолчанию выходы: заказы, к оплате, оплачено, долг. Остальные метрики (без отмен, средний чек, просрочка, прогноз месяца и т.д.) добавляют кнопкой **+** или ПКМ по порту.
- **Группа** — растягиваемая рамка без расчётов: имя, цвет, ручка размера справа внизу. Всё, что лежит внутри, едет вместе с группой; при отпускании ноды у границы она сама заходит внутрь или выходит наружу (порог 50%). Группы всегда под остальными нодами. Кнопка **∅** группы не удаляет.
- **Комментарий** — записка на схеме, сразу после «Группы» в меню. Портов нет, в расчёт не входит. Внутри поле, куда пишут текст. Кнопка **∅** её не удаляет.
- **Схема** — нода другого блюпринта. Её выходы — именованные результаты той схемы.
- **Презентация** — нода блока со страницы презентации. Входы соответствуют портам блока (значение, цель, A/B и т.д.). Один и тот же вход блока может быть занят только одной связью во всём отчёте: если порт уже подключён на другой схеме, он серый и заблокирован; ПКМ по порту — «Освободить вход». Удаление блока в разделе «Презентация» снимает все его ноды со всех схем.

Справа от меню — поле схемы. Связь тянут **с выхода на вход или со входа на выход**; при наведении порты подсвечиваются. Цвет линии зависит от типа ноды (у позиций заказа — ещё и от вида строки). Если тянуть от входа к выходу: левый клик подключает как обычно, правый по выходу позиции открывает то же меню доп. полей. Если нода выделена, анимация бежит **только по входящей цепочке** — от исходных нод до выделенной. Заказы в меню — от новых к старым. С одного заказа можно вести сколько угодно связей. Снять связь — крестик на линии или на входе, либо `Alt`+клик по входу. Слева вверху поля — кнопка **↻** (полный пересчёт), переключатель **⛓** (тянуть цепочку входов), **▣** (плавающее окно блоков презентации) и **∅** (убрать ноды без связей; ноды «Схема», «Группа» и «Комментарий» не трогает). Справа внизу — **навигатор схемы** (кнопка-глазик скрывает и показывает его): показывает все ноды и рамку текущего вида, обновляется при переносе, добавлении и удалении; клик или перетаскивание по навигатору переносит обзор. Колесо меняет масштаб, пустое место сдвигает чертёж. Крестик на ноде или `Delete` удаляет выбранную, `Ctrl+D` дублирует её рядом (связи не копируются), `Esc` отменяет тянущуюся линию.

**Плавающее окно «Презентация»** (кнопка **▣** на поле) видно только в калькуляторе. Его можно перетаскивать за заголовок. Внутри — страницы и блоки со входами из раздела «Презентация» (заголовок, заметка и отступ скрыты: у них нет портов). Блок перетаскивают на схему или кликают — появляется нода. У каждого блока в списке статус: **На схеме** / **Другая схема** / **Не на схеме**. Наведение на блок «На схеме» подсвечивает его ноду на холсте. После добавления ноды позиция прокрутки списка не сбрасывается.

Сверху **вкладки схем**, как в браузере: одна строка, лишние листают колесом без вертикальной полосы; вкладки можно перетаскивать и менять местами. Имя схемы стоит в правом верхнем углу поля и там же его меняют. Всё это пишется в файл отчёта вместе с заказами и откатывается из истории.

## Раздел «Презентация»

Вкладка в боковом меню сразу после «Калькулятора». На телефоне раздела нет: страницы собирают только на компьютере.

Презентация — холст инфографики из блоков. Числа в блоки приходят из калькулятора: на схеме открывают плавающее окно **▣**, ставят ноду блока и соединяют выходы схем (или заказов, формул…) со входами блока.

**Вкладки страниц** сверху — как у схем калькулятора: несколько страниц в одном отчёте, переименование, добавление и закрытие. Имя активной страницы правится в поле на холсте.

**Левая панель** — каталог блоков. Клик или перетаскивание на холст добавляет блок. Типы:

| Блок | Назначение | Входы |
| --- | --- | --- |
| KPI | Крупная метрика и цель | значение, цель |
| Метрика | Число с подписью | значение |
| Сравнение | Два значения рядом | A, B |
| Динамика | Сейчас vs было, % изменения | сейчас, было |
| Прогресс | Шкала выполнения | значение, максимум |
| Столбцы | До четырёх столбцов | A–D |
| Доля | Часть от целого (кольцо) | часть, целое |
| Заголовок / Заметка / Отступ | Оформление страницы | нет |

Блоки **Заголовок**, **Заметка** и **Отступ** есть только на холсте презентации — в плавающее окно калькулятора они не попадают.

**Холст.** Страница имеет фиксированный логический размер (по умолчанию 1200×800) и **вписывается в окно** без ручного панорамирования и зума. Блоки перетаскивают и меняют размер за угол (сетка 10px); они не выезжают за края страницы. Содержимое тянется на всю площадь блока: полоса прогресса и текст масштабируются вместе с размером. Тени блоков лежат на отдельном слое под всеми карточками — падают на фон страницы, а не друг на друга. У страницы можно задать фон и показать сетку 10px (когда блок не выбран — эти настройки в правой панели).

**Правая панель** — инспектор выбранного блока (или настройки страницы). Сворачивается в узкую полоску кнопкой **› / ‹**; состояние запоминается в отчёте и в `localStorage`. Боковые панели по высоте совпадают с окном: если содержимого больше — появляется прокрутка.

**Кастомизация блока:**

- пресеты вида: карточка, стекло, заливка, контур, плакат, неон, мягкий, голый;
- заливка: авто / цвет / градиент / стекло / нет;
- цвета фона, текста, подписи, акцента и рамки (сброс × сразу показывает цвет по умолчанию);
- выравнивание, жирность шрифта, отступ, масштаб шрифта, скругление, толщина рамки, тень, непрозрачность;
- показ подписи, порядок слоёв (вперёд / назад), дублирование и удаление.

Удаление блока с холста снимает связанные ноды «Презентация» со всех схем калькулятора. Подсказки у кнопок **i** в панелях открываются на всю ширину панели, без системной всплывашки `title`.

## Раздел «Облако»

Интерактивная карта отчёта на canvas. Есть два режима: **система текущего файла** и **карта галактик** — все отчёты как отдельные галактики.

KPI (заказы, позиции, оборот, долг) стоят в шапке по центру, между подписью «живая физика» и строкой `LIVE RELATIONSHIP ENGINE`.

### Система текущего отчёта

Три уровня: **заказчик → заказ → позиция**. В 3D заказчик — звезда с мягким сиянием, заказ — планета, позиция — спутник. Сплошные линии — только эти связи. Пунктир между заказчиками не хранится в файле: это визуальная сетка (ближайшие на карте плюс общие типы работ). Расходные строки в облако не попадают.

**Четыре геометрии:**

- **Звёздные системы** — у каждого заказчика своя система: звезда в центре, заказы на орбитах, позиции — луны.
- **Орбитальное кольцо** — те же системы, выстроенные по кругу.
- **Финансовая ось** — заказы слева направо по дате, по вертикали — по сумме.
- **Созвездия работ** — позиции группируются по типу работы; между заказчиками с похожим портфелем рисуются пунктирные мосты.

**Визуальное кодирование:** цвет — статус, заказчик, оплата или тип работы; размер — сумма, долг, количество или одинаковые узлы. Красная дуга — доля долга. Кнопка `♨` включает тепловую карту долга. Кнопка **3D** поднимает карту в объём: левая кнопка вращает обзор, средняя сдвигает камеру. После выделения объекта центр орбиты переносится на него; сдвиг средней кнопкой отвязывает центр от выделения, чтобы масштаб и вращение шли за новым видом.

Выделение звезды приближает камеру так, чтобы вся её система попала в кадр; заказ — планета вместе со спутниками; спутник — ещё ближе.

**Поиск и фильтрация:** поле ищет по номеру, заказчику, названию, продукту, типу и статусу. Клавиша `/` сразу в поиск. Тумблер **«Только долг»** оставляет неоплаченные позиции. KPI считаются по видимой выборке.

**Управление картой:**

- колесо — масштаб; в 2D перетаскивание пустого места двигает карту, в 3D левая кнопка вращает, средняя сдвигает;
- узел можно перетащить, клик фиксирует его в инспекторе справа;
- двойной клик или `Enter` открывает заказ в разделе «Заказы»;
- стрелки переходят между соседними узлами, `F` вписывает весь граф, `T` — автотур по очагам долга;
- клик по мини-карте прыгает в область; `+` / `−` меняют масштаб, соседняя кнопка — полный экран, `⊙` вписывает граф;
- `Aa` скрывает подписи, `◉` ставит физику на паузу, `3D` переключает плоскую карту и объём;
- при выборе узла несвязанные данные приглушаются.

Инспектор показывает оборот, оплату, долг, собираемость, статус, тип, количество и дату. Из него можно открыть заказ, создать снимок, оставить на карте связи заказчика или центрировать узел.

### Карта галактик

Кнопка **«Галактики»** в панели облака. Каждый файл — отдельная галактика:

- отчёты из папки `Документы\FinMaster`;
- недавно открытые файлы, если их путь **не совпадает** с файлом из этой папки.

Размер зависит от объёма отчёта (заказы, позиции, размер файла). Типы разные, чтобы файлы отличались: спиральная, пересечённая, эллиптическая, линзовидная, клочковатая, неправильная. Имена галактик видны всегда, даже если в системе отчёта подписи выключены; кнопка `Aa` на карте галактик скрыта.

**Двойной клик** по галактике: камера влетает в диск, затем открывается этот отчёт (внутри — звёздные системы файла). На стартовом экране достаточно **одного клика**. Если текущий файл не сохранён, программа спросит: сохранить, открыть без сохранения или отмена.

Пока на телефоне открыта вкладка **«Отчёты»**, на компьютере показывается эта же карта галактик (на стартовом экране или в облаке, если отчёт уже открыт). Открытие файла с телефона не выкидывает компьютер с облака на дашборд.

Настройки геометрии, цвета и размера на карте галактик не нужны и скрыты. Карта всегда в объёме: тёмный космос, без сетки «пола».

Движок — Canvas 2D, без внешних библиотек: force-directed физика внутри отчёта, перспективный 3D-вид, тепловая карта долга, поддержка `prefers-reduced-motion`. Цвета и фон следуют теме; карта галактик всегда тёмная.

## Раздел «Хранилище»

Личный учёт денег. С заказами, кассой и аналитикой не связан — это отдельная «записная книжка» для своих средств.

- **Страницы** — вкладки сверху, как в калькуляторе и презентации. У каждой своё название (например «Отпуск», «Новый телефон»), свои строки и своя цель. Кнопка `+` добавляет страницу, `×` на вкладке удаляет (с подтверждением).
- **Строки** — название, сумма, дата и тип:
  - **Пополнение** (`Ctrl+Q`) — деньги пришли (карманные, зарплата): плюс к деньгам на руках;
  - **Снятие** (`Ctrl+W`) — деньги потрачены: минус из денег на руках;
  - **Копилка** (`Ctrl+E`) — отложили в копилку: деньги уходят с рук в копилку. Сумма с минусом — достали из копилки обратно.
- **Итоги страницы:** «На руках» = пополнения − снятия − копилка, «В копилке», «Пополнено», «Потрачено».
- **График** — блок под итогами, по умолчанию свёрнут (раскрывается нажатием на «▸ График»). Два режима: «Остатки» — линии «На руках» и «В копилке» по датам (на конец каждого дня), «По месяцам» — столбики «Пополнено», «Потрачено», «Отложено» по 12 месяцам выбранного года (переключатель года `‹ 2025 ›` и кнопки годов, по умолчанию — последний год с данными). График остатков масштабируется: колесо мыши приближает и отдаляет вокруг курсора, перетаскивание сдвигает приближенный участок, двойной клик возвращает весь период; быстрые кнопки «Всё», «Год», «3 мес», «Месяц» (от последней даты), рядом — видимый диапазон и число точек. Переключатель «Копилка» прячет линию копилки и столбики «Отложено» — шкала подстраивается под оставшиеся данные (удобно, когда в копилке миллион, а на руках десятки тысяч). При наведении — подсказка с суммами.
- **Цель копилки** — необязательная сумма; полоса прогресса показывает, сколько уже отложено и сколько осталось.
- **Таблица** идёт от новых строк к старым; у каждой строки видно, сколько было на руках и в копилке после неё. Все поля правятся прямо в таблице, фильтр — по типу строк. Enter в форме добавляет строку.

Данные хранятся в файле отчёта (`ui.vault`) и попадают в историю изменений (Ctrl+Z).

## Раздел «Заказчики»

Справочник контактов: имя, организация, телефон, почта, адрес, рейтинг звёздами, время совместной работы (считается с даты первого заказа) и количество заказов. Новые имена, введённые в заказах, попадают в справочник автоматически; имя из справочника подсказывается при заполнении заказа.

## Раздел «Справочники»

Четыре редактируемых списка, всё перетаскивается и переименовывается. Имена внутри каждого списка уникальны: одинаковое название ввести нельзя (без учёта регистра и пробелов по краям), кнопка «+» сама добавит суффикс `2`, `3`… Новое имя сразу подставляется во все заказы: статус и единица — в строки, тип заказа — в поле типа, продукт — в название позиции. То же с заказчиком в разделе «Заказчики». **Удалить элемент справочника нельзя**, пока он где-то используется: кнопка неактивна, в подсказке — сколько позиций (для единиц — ещё и шаблоны продуктов).

- **Статусы заказа** — имя и цвет. Флаг «оплачено» помечает статус полной оплаты (такой статус в отчёте один). Замок защищает статус от массовой смены через общее поле заказа — так «Отменено» или «Черный список» не снесёт одним кликом.
- **Единицы измерения** — по умолчанию `шт.`, `м²`, `м`, `мин`; можно добавить свои.
- **Типы заказа** — по умолчанию Производство, Услуга, Поставка, Монтаж. У каждого типа есть две галочки — **Налог** и **Затрата** (можно выбрать только одну). Смена налога на затрату, затраты на налог, включение любой из пометок и снятие пометки спрашивают подтверждение в окне программы: строки в заказах от этого меняются. Тип с галочкой становится расходом: подробности ниже, в разделе [Налоги и затраты](#налоги-и-затраты).
- **Продукты** — три вкладки шаблонов: **Заказы**, **Затраты**, **Налоги**. У каждого вида свой список (имена уникальны внутри вкладки). Для заказов и затрат — название, единица и цена/сумма за ед.; для налогов дополнительно поле **%** по умолчанию. При выборе шаблона в строке подставляются ед. и сумма (сумму не затирают, если уже введена); у налога ещё и процент, если он задан в шаблоне. Подсказки в поле «продукт / за что» показывают только шаблоны своего вида. В справочник попадает только готовое имя после выхода из ячейки, а не каждая буква по мере набора.

Статусы по умолчанию: Новый заказ, Выполняется, Ожидание, Не оплачено, Оплачено, Отменено, Аннулирован, Черный список.

## Налоги и затраты

Отметьте тип заказа галочкой **Налог** или **Затрата** в справочниках — и любая позиция с этим типом перестаёт быть выручкой и становится расходом.

**Как выглядит расход.** В карточке заказа такие строки уходят в отдельный блок **«Расходы заказа»** под основной таблицей. У них нет скидки, оплаты, даты оплаты и статуса — только тип, вид (налог или затрата), за что, расчёт, количество, сумма за единицу, дата и итог со знаком минус. Кнопка **«+ Расход»** в подвале заказа добавляет такую строку сразу; она появляется, только если хотя бы один тип отмечен галочкой. Достаточно сменить тип в обычной строке на «расходный» — строка сама переедет в блок расходов (и обратно).

**Налог процентом.** У новой строки налога по умолчанию стоит **% от выручки**. В столбце **«Расчёт»** три варианта:

- **% от выручки** — процент от всей выручки заказа (доходные строки после скидок);
- **% от выручки − затраты** — процент от выручки, из которой уже вычтены затраты;
- **своя сумма** — как у затраты: количество × сумма за единицу.

В режиме процента вместо количества и цены остаётся одно поле с процентом, а рядом подписана база: `% от 12 000 ₽`. База пересчитывается на ходу при правке любой строки заказа, а налог никогда не считается от другого налога. На телефоне то же самое: в редакторе строки появляются чипы «Своя сумма», «% от выручки», «% от выручки − затраты» и поле «Процент, %». В проценте, как и в остальных числах, работают формулы (`13+7`).

**Как считается.** Расход не попадает в выручку, оплаты и долги — он вычитается отдельной суммой:

- в подвале заказа: `расход −N ₽ · чистыми N ₽`;
- на дашборде: плитки **«Расходы»** и **«Чистыми»**, карточки выводов «Налоги и затраты» и «Чистая прибыль», вторая линия «Расходы» на графике динамики;
- в аналитике: вторая линия на графике, столбцы «Расход» и «Чистыми» в сравнении периодов, отдельная строка итогов под таблицей;
- на телефоне: свой блок «Расходы» в заказе, плитки «Расход» и «Чистыми» в сводке, полосы «Налоги и затраты» и «Чистыми».

**Куда расход не попадает.** В кассу (расход не создаёт дебиторки) и во внутреннюю карту облака (звёздные системы текущего файла). В снимке для заказчика расходы по умолчанию скрыты, но их можно включить полем **«Налоги и затраты»** — см. [Снимок для заказчика](#снимок-для-заказчика). В экспорте CSV расход виден всегда: столбец **«Вид»** показывает «доход», «налог» или «затрата», сумма попадает в столбец «Расход».

Переименование типа, статуса, единицы, продукта или заказчика в справочниках сразу подтягивает новое имя во все существующие строки и заказы, так что галочка налога/затраты и цвет статуса не «отклеиваются» от позиций.

## Снимок для заказчика

Красивая картинка или текст с составом заказа — то, что отправляют клиенту вместо скриншота таблицы.

- **Заголовок** снимка задаётся вручную.
- **Оформление** — 7 тем: Изумруд, Графит, Индиго, Золото, Вишня, Минимал, Ночь.
- **Поля** — 17 доступных: номер, имя заказчика, организация, название, тип/работа, продукт, количество, дата заказа, статус, цена, скидка, сумма позиции, оплачено, не оплачено, дата оплаты, итоги заказа, налоги и затраты. Готовые наборы: «Только работы» (без цен — для согласования состава), «Счёт» (с ценами и итогами), «Все поля».
- **Налоги и затраты** — отдельное поле. Пока оно выключено, расходные позиции в снимок не попадают (так было раньше по умолчанию). Если включить, они встают в таблицу вместе с обычными строками: в столбце типа приписано «налог» или «затрата», сумма идёт с минусом, вместо количества у процентного налога стоит `10 %`, а вместо цены — база процента. Скидки, оплаты и статуса у таких строк нет — в этих столбцах прочерк. Итог таблицы становится суммой **после** вычета расходов, а в строке итогов добавляются `расходы −N ₽` и `к оплате N ₽`. Работает одинаково в PNG, тексте, на телефоне и в Telegram-боте.
- **Скрытие** подписей полей и даты формирования — для совсем лаконичного вида. В подписи «Сформировано» остаётся дата и время; в самих заказах и позициях время не показывается.
- **Профили полей** — набор полей, скрытие подписей/даты и галочку общего итога можно сохранить под своим именем и потом включать одним нажатием. Профили общие для всех отчётов на этом компьютере; профиль с тем же именем перезаписывается.
- **Выбор заказов и строк** — можно исключить отдельные позиции из снимка. Кнопки «Все», «Долг», «Оплата» и «Снять все» ставят галочки сразу: «Долг» — только позиции с остатком, «Оплата» — только полностью оплаченные. Строка поиска над списком фильтрует по номеру, названию, заказчику, типу и продукту позиции (несколько слов — все должны совпасть, Esc очищает); при активном поиске «Все» и «Снять все» действуют только на найденное, а скрытые поиском галочки не меняются. Расходные строки в списке подписаны «налог» / «затрата», чтобы их было видно. Замороженные позиции в снимок не попадают. Выбор, заголовок и свёрнутые блоки сохраняются при закрытии окна до конца сеанса.
- **Предпросмотр** обновляется на ходу. Количество, скидка и проценты округляются до сотых, без «хвоста» вроде `1,333333`.
- **Несколько заказов.** Колонки всех таблиц выравниваются по одной сетке — одинаковые ширины во всех заказах. Галочка **«Общий итог по всем заказам»** (включена по умолчанию) добавляет в конец сводную таблицу: сумма, расходы, к оплате, оплачено и остаток по каждому заказу и строка «Всего».
- **Результат** — кнопки-значки внизу окна: копировать текстом (TXT), копировать PNG в буфер, сохранить PNG в файл, открыть PDF. Полное название действия — во всплывающей подсказке.
- **PDF** открывает предпросмотр страниц A4: каждый заказ — на своей странице (длинная таблица переносится на следующую с повтором заголовков колонок), общий итог — отдельной страницей с карточками сумм, без цветной шапки (только заголовок «Общий итог»). Инструменты слева: ориентация, поля, шапка на каждой странице, номера страниц, номер и название заказа в шапке вместо «Заказы (N)» (для нескольких заказов, вида `123 · Кухня`), обрезка страниц по высоте таблицы (без пустого места внизу; длинные таблицы всё равно переносятся по высоте A4); выравнивание таблицы (слева, по центру, во всю ширину), чисел и заголовков колонок; переключатель листа «Общий итог» (независим от галочки общего итога в снимке); шрифт, размер текста (70–200 %; широкая таблица всегда ужимается по ширине листа), высота строк, полосы через строку, вертикальные линии, жирные итоги. Настройки запоминаются. Вверху панели — **«Мои профили»**: весь набор настроек PDF можно сохранить под своим именем (например «Для бухгалтерии», «Компактно альбомная») и включать одним нажатием; профиль, совпадающий с текущими настройками, подсвечен. Профили общие для всех отчётов на этом компьютере, профиль с тем же именем перезаписывается. Страницы PDF собираются текстом и линиями, а не картинкой листа: вид как в предпросмотре, текст выделяется, файл заметно легче.

Набор полей и выбранная тема запоминаются в файле отчёта.

## Экспорт CSV

Кнопка «Экспорт CSV» в верхней панели выгружает все **живые** позиции отчёта: номер, заказчик, название, начало и конец работ, тип, продукт, количество, единица, цена, скидка, итог, оплачено, не оплачено, даты заказа и оплаты, статус. ## Ассистент

В открытом отчёте ассистент сразу виден как светящийся круг в левом нижнем углу, поверх остальных элементов. Щелчок по кругу превращает его в окно. `Ctrl+Пробел`, кнопка «—», двойной щелчок по заголовку или `Esc` превращают окно обратно в круг. `Ctrl+K` и `Ctrl+Shift+P` делают то же, что `Ctrl+Пробел`. Окно открывается над кружком. Если увести курсор за границу окна или увести из него фокус, оно за 3 секунды тускнеет до половины и ещё через 2 секунды само сворачивается в круг. Пока фокус в поле поиска, окно только тускнеет и не сворачивается; набранный символ возвращает яркость. Курсор снова внутри окна — яркость и фокус возвращаются. Окно можно перетащить за заголовок и потянуть за правый нижний угол. Выбор команды не меняет список и строку поиска. Навигация `↑` `↓`, выполнение `Enter`.

Ассистент умеет:

- переходить в любой раздел — Дашборд, Заказы, Аналитика, Касса, Прогнозирование, Календарь, Калькулятор, Презентация, Облако, Заказчики, Справочники;
- выполнять действия — сохранить, сохранить как, открыть, создать, экспорт CSV, снимок заказов, отмена/повтор, свернуть боковую панель, консоль сети, подсказка;
- открывать кассовые сценарии — например, показать просроченные долги или скопировать сводку;
- сразу открывать календарь на заказах в работе;
- искать по содержимому отчёта: наберите номер заказа, имя заказчика или название продукта — палитра предложит перейти к нужной карточке.

**Отмена и история.** Между стрелками отмены и повтора — часы. В панели видны снимки после каждого действия с данными отчёта: подпись называет саму правку (заказ и поле, было → стало). Сдвиг и масштаб схемы, открытая вкладка, ширина колонок и боковая панель отдельным снимком не записываются. Рядом устройство — «ПК» или имя телефона. Кнопка «≠» у снимка открывает сравнение с открытым отчётом: правки собраны по заказу и позиции, в строке только поле, значение до и значение после. `Ctrl+Z` / `Ctrl+Y` ходят по этим снимкам, можно ткнуть конкретный. Если отойти на несколько шагов назад и сделать новое действие, более поздние снимки пропадают; пока новой правки нет, к ним ещё можно вернуться. Если закрыть отчёт без сохранения, шаги после последнего сохранения удаляются. Сколько снимков хранить, задаётся в той же панели (по умолчанию 40). Кнопка «Все истории отчётов» открывает список папок: путь к файлу (и в FinMaster, и снаружи), пометку если файл уже удалён, число снимков и размер; ненужные истории можно стереть. Снимки лежат в `Документы\FinMaster\history\<название отчёта>\` — `meta.json` и отдельные JSON на каждый снимок. При открытии отчёта эта папка подхватывается целиком, старые снимки не сбрасываются. Правка с телефона тоже попадает в историю.

**Резервные копии.** В том же окне истории кнопка «Резервные копии» открывает список копий текущего отчёта (вкладка «Этот отчёт»). «Создать копию» пишет файл `.fbak` в `Документы\FinMaster\backups\<номер отчёта>\`. Папка привязана к номеру внутри файла, а не к названию: два отчёта с одним именем не смешивают копии. «До/после» сравнивает копию с открытым отчётом: слева копия, справа отчёт. «Смотреть» открывает копию только для чтения; «Вернуться к отчёту» на полосе просмотра открывает файл, из которого ушли. «Сохранить как отчёт» записывает её отдельным `.fmaster` с новым номером — после этого файл можно править, а копии исходного отчёта остаются на месте. Удаление отправляет `.fbak` в корзину Windows. Вкладка «Другие отчёты» показывает копии остальных номеров, в том числе если сам файл отчёта уже удалён: у такой строки написано «файла нет на диске». «Удалить все» на строке отчёта отправляет в корзину сразу все его копии, сам файл отчёта не трогает. «До/после» на этой вкладке нет.

## Управление с телефона

Кнопка **«Телефон»** в верхней панели. Телефон подключается напрямую к компьютеру — промежуточных серверов нет.

1. Нажмите **«Включить доступ»** — появится QR-код и ссылка вида `http://192.168.0.10:17891/m?t=…`.
2. Наведите камеру телефона на код или откройте ссылку в мобильном браузере.
3. Добавьте страницу в закладки: токен и порт постоянные, второй раз сканировать не нужно.

Под QR-кодом — чипы с локальными IP-адресами и «Интернет»: ими выбирается, куда ведёт код, если у компьютера несколько сетевых адресов.

**В окне подключения:**

- **Включить доступ** — открывает веб-интерфейс с телефона. Состояние запоминается и поднимается снова при следующем запуске программы.
- **Через интернет (ngrok)** — см. следующий раздел.
- **Токен ngrok**, **Telegram**, **Устройства** — три сворачиваемых блока, чтобы окно не разрасталось. У заголовков «Токен ngrok» и «Telegram» горит точка-индикатор: серая — токен не сохранён, зелёная — сохранён, голубая — работает прямо сейчас (туннель поднят / бот слушает), красная — токен есть, но сервис вернул ошибку. Пока окно открыто, точки и текст статуса обновляются сами. Кнопка **«Проверить связь»** в каждом блоке спрашивает сервис заново: ngrok — локальный туннель, Telegram — `getMe`. Наведите курсор на точку — подсказка расскажет подробности.
- **Устройства** показывают подключённые телефоны в реальном времени: заголовок блока и список обновляются сами, пока окно открыто — видно имя (его задают на телефоне), кто онлайн, с какого адреса и когда заходил последний раз. Любое устройство можно забыть.
- **Консоль** — плавающее окно с сетевыми событиями: включения доступа, телефоны в сети, синхронизация отчёта, команды, Telegram и ngrok. Перетаскивается за заголовок, вызывается кнопкой в окне подключения, из ассистента или `Ctrl+Ё`. `Esc` закрывает консоль.
- **Новая ссылка** — сбрасывает только токен сессии телефона: старые закладки перестают работать, устройства отключаются. Токены ngrok и Telegram и сам бот не трогаются. Кнопка **«Открыть»** в боте (меню и клавиатура) сразу получает новый адрес, в чат приходит короткое сообщение. Подтверждение — в том же стиле, что остальные окна программы.
- **Выключить доступ** — закрывает сессию. Токены ngrok и Telegram при этом сохраняются, вводить их заново не придётся.

Кнопка `i` в заголовке окна открывает отдельное руководство по подключению.

Всё, что делается на телефоне, сразу видно на компьютере — и наоборот. Переход по разделам тоже зеркалится: открыли на телефоне «Заказы» — на компьютере откроется тот же раздел, открыли конкретный заказ — компьютер перейдёт на дашборд и покажет цифры именно этого заказа. Фильтры сводки (период, долг/оплата, статус) на дашборде компьютера следуют за телефоном. Калькулятор на телефон не выводится — схемы и презентацию собирают только в окне программы.

Если на компьютере нет открытого отчёта, телефон сразу показывает вкладку «Отчёты»: папка FinMaster и недавние файлы. На компьютере в этот момент открывается карта галактик (на стартовом экране или в облаке). Выбор другого отчёта на телефоне открывает его в окне программы и переключает телефон на вкладку **«Заказы»**. Удаление с телефона или в проводнике сразу убирает файл со стартового экрана компьютера и из списка на телефоне. Если текущий отчёт не сохранён, смена галактики на компьютере спрашивает подтверждение.

Каждое устройство можно назвать: имя видно в списке «Устройства». Кнопка `i` на телефоне показывает модель, систему и браузер.

## Доступ через интернет (ngrok)

Чтобы заходить не только из своей Wi-Fi:

1. Проще поставить ngrok из Microsoft Store: после установки он уже в `PATH`. Либо скачайте его с [ngrok.com/download](https://ngrok.com/download), распакуйте и добавьте программу в `PATH`.
2. Зарегистрируйтесь на ngrok.com и скопируйте **Your Authtoken** из кабинета.
3. В окне «Телефон» включите **«Через интернет (ngrok)»**, вставьте токен в блок «Токен ngrok» и нажмите **«Сохранить и включить»**.
4. QR сменится на адрес вида `https://….ngrok-free.app/m?t=…` — его и сохраняйте в закладки телефона.

Нюансы: на бесплатном тарифе адрес меняется после перезапуска — скопируйте ссылку заново (или спросите её у Telegram-бота). При первом открытии ngrok может показать свою страницу-предупреждение — нажмите **Visit Site**. Токен хранится только на этом компьютере и не забывается при выключении тумблера.

## Telegram-бот

Бот — отдельный вход в те же отчёты: не нужно открывать браузер на телефоне. Пока FinMaster запущен, из чата можно смотреть файлы, заказы и собирать снимки. Если включён интернет (ngrok), тот же мобильный интерфейс открывается **внутри Telegram** как Mini App.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В окне «Телефон» → блок **Telegram** вставьте токен и нажмите **«Запомнить токен»**. Chat id заполнять не обязательно — он запомнится при первом `/start`.
3. Включите доступ с телефона и тумблер **Через интернет (ngrok)** — Mini App работает только по HTTPS. Локальный адрес `http://192.168.…` Telegram внутрь чата не откроет.
4. В Telegram нажмите **/start**.

Кнопки внизу чата: **Отчёты**, **Заказы**, **Снимок**, **Открыть** (Mini App, если есть HTTPS), **Ссылка**, **Новая ссылка**, **Меню**. **Снимок** открывает снимок для заказчика по текущему отчёту. Список заказов на снимке — все заказы отчёта, даже если в «Заказах» включены «Долг» или «Оплата»: отмеченный заказ попадает в снимок целиком, если фильтр снимка иначе скрыл бы его. **Новая ссылка** сначала спрашивает подтверждение, затем выпускает тот же новый адрес, что кнопка в окне «Телефон»: старые закладки отваливаются, бот остаётся на связи, «Открыть» обновляется. Слева в поле ввода — кнопка меню бота **Открыть**. Команды: `/start`, `/reports`, `/orders`, `/snap`, `/link`, `/newlink`. Если после текущего меню в чате уже есть сообщение — ваш текст, снимок, файл — повторный вызов меню, отчётов или заказов присылает это меню ещё раз в конец переписки. Пока меню последнее, бот правит его на месте.

Адрес Mini App обновляется сам, когда меняется ngrok или токен сессии. Если туннель ещё не готов или доступ выключен, кнопка меню снова показывает обычные команды.

**Отчёты** — тот же список, что на стартовом экране: папка `Документы\FinMaster` и недавние файлы. Выбор отчёта открывает его заказы. Если этот файл сейчас открыт на компьютере, бот показывает живые данные вместе с несохранёнными правками. Кнопка «Открыть на компьютере» просит программу показать тот же файл в окне.

**Заказы** — список с суммой и долгом, фильтры «все / с долгом / оплаченные», страницы. Напишите номер, имя заказчика или продукт — бот отфильтрует. Карточка заказа: заказчик, итог, оплата, долг, все позиции и заметки.

**Снимок** — как на компьютере, без урезанного режима:

- наборы «Для работы», «Как счёт», «Коротко», «Все поля» и ручное включение полей (шапка заказа и столбцы таблицы — в отдельных группах);
- пользовательские профили полей с компьютера (если сохранены);
- темы, подписи, дата и заголовок — в разделе «Оформление»;
- выбрать позиции и добавить несколько заказов на один снимок (замороженные позиции в снимок не входят); кнопки **Все / Долг / Оплата** отмечают соответствующие позиции; в списках позиций и заказов — «Выбрать все», «Снять все», «Инверт.» и статусы только из текущих позиций (повторный статус добавляет выбор, не сбрасывая предыдущий); «Готово» без выбора предупреждает;
- результат — картинка PNG, PDF или текст (длинный текст приходит файлом). PDF берёт заказы, поля, тему и заголовок из меню снимка в боте. Кнопка **По умолчанию** оставляет обычную вёрстку страницы (книга, обычные поля, 100%); сохранённые шаблоны страницы с компьютера по-прежнему можно выбрать отдельно. Окно FinMaster должно быть открыто;

Выбор полей, позиций и заказов не сбрасывается при возврате кнопкой «Готово».
**Ссылка** — сразу два адреса: **Телефон** и **Интерфейс ПК**, у каждого своя кнопка. По HTTPS телефон открывается как Mini App, по HTTP — в браузере. В тексте тип подключения (`ИНТЕРНЕТ` / `ЛОКАЛЬНАЯ СЕТЬ`) и предупреждение, если на компьютере выключен доступ или ngrok. Кнопка **«Включить доступ к веб»** / **«Выключить доступ к веб»** переключает тот же доступ, что тумблер в окне «Телефон». Такая же кнопка есть в **Меню**. На бесплатном ngrok при первом заходе может появиться страница **Visit Site** — это ограничение туннеля, не FinMaster.

Бот отвечает только тому чату, который первым написал `/start` (или чей chat id указан в окне «Телефон»). Кнопка **«Отправить ссылку сейчас»** по-прежнему шлёт ссылку, не вставая из-за компьютера.

## Мобильный интерфейс

Открывается по ссылке `/m?t=<токен>` — из браузера или как Telegram Mini App. Внутри Telegram приложение сразу запрашивает полный экран (как игры): шапка мессенджера становится прозрачной, остаётся системный крестик закрытия. Нужен Telegram с поддержкой Mini App fullscreen (примерно с конца 2024). Наверху — отмена, повтор и меню, ниже — строка синхронизации с состоянием связи.

В меню `⋯` справа вверху — квадратные кнопки рядом с заголовком и широкая «Сохранить на компьютере». Ниже отдельной строкой **Интерфейс ПК** — тот же экран, что на компьютере. Плитки под ней ровные, по две: снимок, новый отчёт, ссылка, отчёты. В браузере слева от темы — полный экран. Справа от темы — проверка связи с компьютером: запрос к программе и сообщение, есть ли подключение. Внутри Telegram полный экран скрыт (Mini App и так развёрнут), на его месте — ярлык **на домашний экран**, как у игр. Тот же пункт есть в «Отчёты» → «Это устройство». Если Telegram ответит, что ярлык недоступен, в [@BotFather](https://t.me/BotFather) включите Mini App и задайте иконку: `/mybots` → бот → Bot Settings → Configure Mini App.

**Пять вкладок:**

- **Заказы** — поиск, сортировка, воронка фильтра (все / с долгом / оплачены / этот месяц) и список заказов. На карточке — номер и название заказа, суммы и цветные точки статусов всех позиций; одновременно видно не больше 10, остальные плавно качаются туда-сюда с замедлением на краях. Комментарий заказа и позиции — фиолетовая плашка со значком i. Точка позиции с комментарием отмечена светлым кольцом внутри. Кнопка `+` создаёт заказ.
- **Календарь** — на телефоне три вида иконками: месяц, неделя и день (таймлайн только на компьютере). При открытии календаря открыт месяц. Выбранный день общий: переключение на неделю или день оставляет его и обводит там же. Если день ещё не выбран, неделя и день берутся от текущего периода (сначала это сегодня). Стрелки в виде «день» и кнопка «сегодня» двигают этот же день, поэтому месяц и неделя потом показывают его. Месяц, неделя и день листаются стрелками и свайпом влево или вправо, как карточка заказа: на месяц, на неделю и на день. День — столбец как в неделе на компьютере — шапка, полоска загрузки, заметка, секции со значками (старт, выполнялось / выполняется / запланировано, пауза, финиш), карточки заказов и позиции под ними. Рядом с «сегодня» иконка паузы без подписи: она прячет и показывает паузы в месяце, неделе и дне. Это та же настройка, что кнопка «скрывать на паузе» на компьютере. Сверху плитки «Идёт / Без дат», затем слева виды, сразу справа с небольшим отступом кнопки «сегодня» и паузы, дальше воронка фильтра, ниже ‹ › с месяцем, неделей или днём. Если этот блок уехал вверх при прокрутке, под шапкой появляется стрелка: нажатие открывает панель с видами, «сегодня», паузой, фильтром и переключением даты. Выходные те же, что заданы на компьютере: обычные — красные, точечные — фиолетовые. В неделе видны только рабочие дни: если суббота глобально рабочая, её заказы попадают в список. Заказ на выходной не ставится: диапазон обрывается до выходного и продолжается со следующего рабочего. Дни паузы, отмеченные на компьютере внутри срока заказа, в сетке тоже не считаются работой. Если пауза доведена до сегодня у заказа без даты конца, она держится и на новые дни, пока её не снимут. На день можно оставить заметку; выбранный день обведён в месяце, в неделе и в дне. Статус работ на карточках и в сетке месяца тот же, что на компьютере: идёт сейчас, запланирован, завершён, без дат. Неделя идёт сверху вниз от позднего дня к раннему (для диапазона 21–27 сверху 27). Фильтр «Без дат» показывает только список без дат, не размазывает их по дням календаря. Пустой конец — нет дедлайна, заказ не просрочен. Если даты ещё нет — «Начать сегодня» / «Закончить сегодня»; если уже стоит — «Сменить начальную/конечную дату» и «Убрать». Календарь на телефоне открывает на компьютере окно «Календарь с телефона»: оно само меняется вместе с месяцем, неделей, днём, выделенным днём, фильтром и кнопкой пауз. День в окне — одна колонка на всю ширину. Вместе с окном открывается раздел «Календарь». Сводка на телефоне открывает дашборд.
- **Сводка** — KPI и выводы по отчёту. Три кнопки фильтров (период, заказы, статус) открывают список вариантов; выбранное видно на кнопке. Внизу блок **«Кто должен»** — карточки с номером и названием заказа, суммой долга и заказчиком. Те же фильтры сразу видны на дашборде компьютера.
- **Снимок** — тот же снимок для заказчика, что и на компьютере: выбор заказа, 4 темы (Бирюза, Золото, Минимал, Ночь), наборы полей, пользовательские профили с компьютера, заголовок, скрытие подписей и даты. Список позиций свёрнут по умолчанию (в шапке видно, сколько строк в снимке) — так кнопки отправки остаются рядом. Свайп влево или вправо листает заказы в том же порядке, что в списке. Если открыть снимок из заказа или другой вкладки, в шапке появляется **‹** — возврат туда, откуда пришли. В браузере картинку можно отправить через «Поделиться» или сохранить PNG в загрузки. Внутри Telegram Mini App системное «Поделиться» и сохранение в Загрузки не работают (WebView не отдаёт файл) — снимок уходит ботом: **«Поделиться в Telegram»** открывает выбор чата, **«Прислать PNG в чат»** кладёт файл в переписку с ботом, откуда его можно сохранить и переслать.
- **Отчёты** — если на компьютере открыт файл, видны название, валюта, точность сумм и сохранение. Дальше общий список папки FinMaster (открыть или удалить в корзину), недавние файлы и блок устройства: имя на компьютере, сведения о телефоне, полный экран, постоянная ссылка и отключение. Список папки обновляется сам, если файл появился или исчез в проводнике. Выбор другого отчёта сразу подтягивает файл и открывает вкладку **«Заказы»**.

Калькулятора и презентации на телефоне нет: нодовые схемы и страницы инфографики собирают в окне программы или в интерфейсе ПК.

**Новый отчёт** спрашивает название и сохраняется в `Документы\FinMaster`. Если файл с таким именем уже есть, программа предложит другое. Пока на компьютере ничего не открыто, телефон остаётся на вкладке «Отчёты» — можно выбрать файл из папки или из недавних.

**Карточка заказа** на телефоне: липкая шапка с номером и названием заказа, список позиций (комментарий позиции — плашка со значком i), кнопки «+ Позиция», «Снимок для заказчика», «Дублировать заказ», «Удалить заказ». Заказчик и даты начала/конца работ — в блоке «Данные заказа». Замороженные позиции, если они есть, стоят отдельным блоком внизу и в итоги не входят; вернуть их можно из редактора строки. Вкладка «Заказы» держит открытую карточку и прокрутку: уход на сводку, календарь или снимок и возврат снова показывает тот же заказ в том же месте страницы. К списку возвращает **‹**. Свайп влево — следующий заказ из текущего списка (с учётом поиска, фильтра и сортировки), вправо — предыдущий. Строки позиций и расходов переставляются за ручку слева, как на компьютере.

**Редактор позиции** — отдельная панель на весь экран со всеми полями строки (тип, продукт, количество, единица, цена, скидка, даты, оплата, статус, комментарий). Стрелки `‹` `›` и свайп влево/вправо листают позиции того же заказа, не закрывая редактор. В количестве, цене и скидке те же формулы, что на компьютере (`2+3×4`, `1200/3`). На телефоне открывается своя клавиатура: цифры и действия; в поле остаётся формула, при уходе фокуса виден результат.

**Отмена и повтор** работают с телефона и применяются к документу на компьютере. В меню под автосохранением — **История**: список снимков только для просмотра (подпись и устройство). Лимит и удаление папок — на компьютере. Изменения летят в обе стороны. Если на компьютере включено автосохранение, правки с телефона сами записываются в файл — не нужно щёлкать галочку на телефоне. Если связь пропала, строка синхронизации пишет «нет связи с компьютером». Как только любой запрос снова проходит (смена вкладки, открытие отчёта, проверка связи, опрос), надпись снимается — она не зависает после включения программы обратно. Когда страница закрывается или нажимают «Отключиться», компьютер сразу видит, что устройство ушло.

## Интерфейс компьютера в браузере

Тот же экран, что в окне FinMaster, открывается по ссылке `/desk?t=<токен>`. Адрес лежит под QR в окне «Телефон» (строка «Интерфейс ПК»), в меню телефона и в Telegram — кнопка **Интерфейс ПК**. Пока нет HTTPS, Telegram присылает обычную ссылку; с ngrok кнопка открывает экран внутри чата.

Блокировки и перехвата управления нет: и браузер, и окно на компьютере можно держать открытыми. Браузер файл себе не сохраняет. Автосохранение в нём по умолчанию выключено: правка остаётся на экране, пока не нажата **Сохранить**. Тогда на главный компьютер уходит только изменение, файл и снимок истории записываются там. В истории пометка того, кто сохранил: **WEB** или **ПК**. Пока данные передаются, видна надпись «Передача на компьютер…». Папка `Документы\FinMaster` остаётся на главном компьютере. Из браузера можно создать отчёт и добавить свой файл `.fmaster`. Закрытие программы, выбор среды запуска и проводник из браузера не вызываются.

## Безопасность

- Доступ с телефона включается вручную и работает, пока открыта программа.
- Telegram-бот показывает отчёты только тому чату, который привязан в окне «Телефон». Не публикуйте бота в открытых группах.
- Ссылка содержит токен сессии; без него запрос с другого адреса отклоняется.
- С телефона по ссылке `/m` открывается мобильный интерфейс. Полный экран компьютера доступен отдельно, по ссылке `/desk`, и только с тем же токеном.
- Токены ngrok и Telegram пишутся в конфиг атомарно и держатся в памяти программы. Пустая строка или опечатка их не затирает — заменить можно только новым действительным токеном.
- «Новая ссылка» мгновенно обнуляет доступ для всех прежних устройств, но бот Telegram продолжает работать.

## Где хранятся настройки

Настройки программы: `%APPDATA%\FinMaster\config.json`.

В нём: список недавних файлов, флаг автосохранения, последняя папка, тема, поле `python_runtime` (`system` или `folder` — чем запускать программу), блок `ui_prefs` (профили полей снимка, профили и текущие настройки PDF, галочка общего итога, профили формул калькулятора, цветовые схемы календаря и тумблеры «переход к началу заказа» и «скрывать на паузе» в календаре — они общие для всех отчётов; отдельно для каждого файла запоминается вкладка, на которой его закрыли. Всё это переживает перезапуск) и блок `remote` — токен сессии, порт, автозапуск доступа, список запомненных устройств (до 20), настройки ngrok и Telegram (токен бота, chat id привязанного чата). Автозагрузка Windows хранится не здесь, а в реестре текущего пользователя. Установка программы — в тех же полях: `installed`, `install_path`, `install_commit`, `update_pending`, `python_place` (`reports`, `program` или `bundled`), `install_shortcuts`, `install_shortcut_desktop` и `install_shortcut_start`. Время последнего скачанного коммита лежит отдельно, в `commit.txt` в папке программы. Список файлов обновления лежит во временном `FinMaster-update.txt`, не в этом конфиге.

Тема, вид стартового экрана (список или галактики), список недавних и свёртка правой панели презентации дополнительно кешируются в `localStorage` интерфейса. Сами отчёты лежат там, где вы их сохранили: в файле — заказы, справочники, вид календаря, **выходные** (дни недели и точечные даты), схемы калькулятора и страницы презентации (блоки, стили, свёртка инспектора). Новые файлы с телефона по умолчанию пишутся в `Документы\FinMaster` — программа эту папку не подменяет и чужие каталоги не трогает.

`FinMaster.exe` собирается только из `starter.py` спецификацией `build/FinMaster.spec`: `py -m PyInstaller --noconfirm build/FinMaster.spec`, результат `dist/FinMaster.exe`. В этот файл попадает запуск. Окно учёта не собирается: Python читает `app.py`, `backend` и страницы как есть.

Файлы в `modules/` сервер отдаёт как есть. В `app/`, `mobile/` и папках стилей части одного скрипта — по-прежнему одна область видимости, не отдельные `import`. Имена с префиксом `01-`, `02-` задают порядок склейки, его нельзя переставлять. На краях разрезанной функции стоит пометка `/* bundle-seam */`: она закрывает файл для редактора, а при отдаче странице сервер её убирает.

## API для разработчика

Запросы с чужих адресов проходят к телефону (`/m`) и к интерфейсу компьютера (`/desk`) только с токеном сессии.

| Маршрут | Назначение |
| --- | --- |
| `GET /` | интерфейс компьютера |
| `GET /m` | мобильный интерфейс |
| `GET /desk` | тот же интерфейс, что на компьютере; в браузере управление у одного окна |
| `GET /api/bootstrap` | стартовые данные: тема, недавние, папка FinMaster, автосохранение, состояние доступа |
| `POST /api/dirty`, `/api/autosave`, `/api/theme` | состояние документа и настройки |
| `POST /api/ui-pref` | сохранить настройку интерфейса в `config.json` (`key`: `share_profiles`, `pdf_profiles`, `share_pdf`, `share_grand`, `formula_profiles`, `cal_follow`, `cal_hide_pause`) |
| `POST /api/dialog/open`, `/dialog/save`, `/dialog/export`, `/dialog/png`, `/dialog/pdf` | системные диалоги |
| `POST /api/write`, `/write-text`, `/write-bytes` | запись отчёта, текста и PNG |
| `GET /api/library` | список отчётов в папке FinMaster |
| `GET /api/library/watch` | длинный опрос: папка FinMaster изменилась (только компьютер) |
| `POST /api/library/delete` | отправить отчёт из папки FinMaster в корзину (только с компьютера) |
| `POST /api/open-folder` | открыть папку FinMaster в проводнике |
| `POST /api/open-path`, `/api/recent/remove` | открыть файл по пути, убрать из списка недавних |
| `POST /api/clipboard-text`, `/api/clipboard-png` | буфер обмена |
| `POST /api/remote/start`, `/remote/stop` | включение и выключение доступа с телефона |
| `POST /api/remote/address` | выбор адреса для QR-кода |
| `POST /api/remote/ngrok` | тумблер и токен ngrok |
| `POST /api/remote/telegram` | токен бота, chat id, отправка ссылки |
| `POST /api/remote/rotate`, `/remote/forget` | новая ссылка, забыть устройство |
| `GET /api/remote/info` | состояние доступа, список устройств и клиентов |
| `POST /api/remote/publish`, `/remote/push` | обмен документом между компьютером и телефоном |
| `GET /api/remote/pull`, `/remote/session` | получение изменений, списка отчётов и данных сессии |
| `POST /api/remote/command`, `/remote/nav` | команды (сохранить, открыть, новый, удалить, отмена, повтор) и зеркалирование навигации |
| `POST /api/remote/leave` | телефон сообщает об отключении |
| `GET /api/remote/desk`, `POST /api/remote/desk/take`, `/beat`, `/leave` | кто из браузеров сейчас управляет интерфейсом |
| `POST /api/remote/desk/path`, `/api/remote/desk/import` | новый файл и загрузка отчёта в папку главного компьютера |
| `POST /api/quit` | закрытие программы |

## Решение проблем

**Телефон не открывает локальную ссылку.** Проверьте, что телефон и компьютер в одной Wi-Fi, и разрешите Python в брандмауэре Windows для частной сети. Если у компьютера несколько адресов, попробуйте другой IP-чип под QR-кодом.

**Ссылка была, а теперь не работает.** Скорее всего адрес ngrok сменился после перезапуска или кто-то нажал «Новая ссылка». Откройте окно «Телефон» и скопируйте актуальную ссылку либо запросите её у бота.

**ngrok не включается.** Программа ngrok должна быть в `PATH`, а токен — вставлен в блок «Токен ngrok». Ошибку подключения окно показывает текстом под кнопкой.

**Бот молчит.** Проверьте токен из @BotFather и что программа запущена. После смены токена напишите боту `/start` заново — chat id подставится сам.

**Бот пишет, что доступ выключен.** Так и задумано: он не включает доступ или ngrok молча. Включите нужные тумблеры в окне «Телефон» и нажмите «Получить ссылку» ещё раз.

**Порт занят.** FinMaster сам подберёт свободный порт и запомнит его — QR-код и ссылка обновятся.

**Интерфейс открылся в браузере, а не в своём окне.** Не установился `pywebview`. Выполните `python -m pip install pywebview`. В браузерном режиме сохранение идёт через скачивание файла.

**Автосохранение не срабатывает.** Отчёт ещё ни разу не сохраняли вручную — программа не знает путь. Сохраните файл один раз, дальше галочка заработает.

**Удалили отчёт по ошибке.** Файл в корзине Windows, не стёрт навсегда. Восстановите его из корзины и снова откройте в FinMaster. Удалять из списка можно только файлы из папки `Документы\FinMaster`.

**При запуске нужна консоль.** Обычный старт — `run.vbs` / `launch.vbs` без чёрного окна. Чтобы видеть сообщения Python, задайте `FINMASTER_CONSOLE=1` и запустите `python launch.py`.
