# FinMaster

Десктоп-программа учёта заказов: Python-сервер (Flask) и HTML-интерфейс в собственном окне (WebView2 на Windows). Всё, что нужно бухгалтеру и финансисту небольшой мастерской или студии: заказы с позициями, оплаты и долги, дашборд, аналитика периодов, платёжный календарь, календарь работ (когда заказ начали и когда закрыли), калькулятор схем из заказов, снимки для заказчика и управление с телефона.

Данные лежат в одном файле отчёта `.fmaster` — как книга Excel. Никаких внешних серверов и облаков: программа работает на компьютере, а телефон подключается напрямую к нему.

## Быстрый старт

Нужен Python 3.10 или новее.

```bat
run.bat
```

`run.bat` запускает программу **без окна консоли**: сначала заставка с прогрессом, затем окно FinMaster. Если пакеты ещё не установлены, заставка сама поставит их из `requirements.txt`.

Или вручную:

```powershell
python -m pip install -r requirements.txt
python launch.py
```

Для отладки с консолью задайте `FINMASTER_CONSOLE=1` и запустите `python launch.py` или `python app.py`.

Откроется отдельное окно FinMaster, а не вкладка системного браузера. Если пакет `pywebview` недоступен, программа откроет интерфейс в обычном браузере — тогда сохранение файла идёт через скачивание, а системные диалоги выбора файла недоступны.

Зависимости: `flask>=3.0.0`, `pywebview>=5.0`.

## Как это устроено

- **`launch.py`** / **`launch.vbs`** — тихий вход: скрывают консоль, показывают заставку, проверяют библиотеки и вызывают `app.py`.
- **`app.py`** — Flask-сервер: раздаёт интерфейс, отвечает на API-запросы, работает с файлами и диалогами Windows, поднимает окно pywebview и (по желанию) удалённый доступ.
- **`frontend/`** — интерфейс: `index.html` + `app.js` + `styles.css` для компьютера, `mobile.html` + `mobile.js` + `mobile.css` для телефона, `charts.js` и `cloud.js` — графики и живое облако заказов на canvas, `calc.js` — нодовый калькулятор (без внешних библиотек).
- **`backend/`** — модули: документ и нормализация (`document.py`), настройки, папка отчётов и корзина (`storage.py`), суммы заказа с учётом налогов и затрат (`finance.py`), снимки для бота (`snapshot.py`), заставка запуска (`splash.py`), системные диалоги (`dialogs.py`), буфер обмена (`clipboard.py`), генерация QR (`qr.py`), сессия телефона (`remote.py`), ngrok-туннель (`tunnel.py`), Telegram-бот (`telegram.py`).

Сервер слушает всю локальную сеть (`0.0.0.0`), но запросы с других адресов пускает только к мобильному интерфейсу и только с правильным токеном сессии. Порт по умолчанию **17891**; если занят, программа сама берёт следующий свободный из 12 соседних, а в крайнем случае — любой свободный, и запоминает его.

## Файлы отчётов

Каждый отчёт — файл `.fmaster` (внутри обычный JSON). В нём лежат заказы с позициями, справочники, заказчики и настройки интерфейса (ширина столбцов, тема снимка, срок оплаты, горизонт прогноза, набор кривых на графиках, блюпринты калькулятора).

- **Новый отчёт** — `Ctrl+N` или пункт «Новый» в меню логотипа FinMaster.
- **Открыть** — `Ctrl+O`, пункт «Открыть» в том же меню, строка в папке FinMaster или в списке недавних на стартовом экране (то же самое во вкладке «Отчёты» на телефоне).
- **Сохранить** — `Ctrl+S`, **Сохранить как** — `Ctrl+Shift+S`. Те же команды — в меню логотипа.
- **Автосохранение** — галочка в блоке «Текущий отчёт». Работает только после первой ручной записи на диск: программе нужно знать путь к файлу.
- При закрытии с несохранёнными изменениями программа спросит подтверждение и предложит сохранить.
- Список недавних хранит до 15 файлов; лишние строки можно убрать крестиком — сам файл при этом не трогается.

**Папка FinMaster** — `Документы\FinMaster` (создаётся сама). На стартовом экране компьютера и во вкладке «Отчёты» на телефоне виден один и тот же список файлов `.fmaster` из этой папки. Если отчёт создали, скопировали или удалили в проводнике, список на компьютере и на телефоне обновляется сам. Кнопка «Открыть папку» показывает каталог в проводнике.

**Удаление отчёта** из папки FinMaster (крестик на компьютере или «Удалить» на телефоне) отправляет файл в **корзину Windows**, а не стирает его навсегда. Список на обоих устройствах обновляется сразу. Восстановить файл можно из корзины обычным способом.

Запись на диск атомарная: файл сначала пишется во временный, потом подменяет старый — питание пропало, отчёт не потерялся.

## Интерфейс

**Стартовый экран** — две колонки: все отчёты из папки `Документы\FinMaster` и недавно открытые файлы. Переключатель **Список / Галактики** меняет вид: список как раньше или карта, где каждый отчёт — отдельная галактика (размер по объёму файла, разные типы спиралей). Состояние переключателя запоминается. На карте один клик открывает отчёт. Кнопки «Новый отчёт», «Открыть файл», «Телефон» и переключатель темы. Список папки обновляется сразу, если отчёт создали, скопировали или удалили в проводнике или с телефона. Если открытый файл пропал из папки, программа оставляет его в памяти и предупреждает.

**Боковая панель** — клик по логотипу FinMaster открывает меню файла: Новый, Открыть, Сохранить, Сохранить как. Ниже блок «Текущий отчёт»: название (его можно править прямо здесь), путь к файлу, галочка автосохранения и справа от неё точка несохранённых изменений. Если автосохранение включено, в файл уходят и правки с компьютера, и с телефона. Дальше навигация по разделам. Панель сворачивается кнопкой с иконкой панели — остаются иконки разделов и логотип.

**Верхняя панель** — поиск по отчёту, кнопка командной палитры, отмена, часы истории снимков и повтор, кнопка «Телефон», переключатель темы, возврат к списку отчётов, экспорт CSV, полный экран окна (`F11`) и подсказка по горячим клавишам.

**Темы** — светлая и тёмная, переключаются в любом месте программы и запоминаются между запусками. Тёмная тема применяется и к мобильному интерфейсу.

**Поиск (`Ctrl+F`)** ищет по номеру заказа, заказчику, названию и продукту, сразу фильтруя список заказов.

**Тосты** — короткие уведомления внизу экрана. У разрушающих действий (удаление заказа, строки, заказчика) в тосте есть кнопка «Отменить».

## Раздел «Заказы»

Главный рабочий раздел. Заказ — это карточка с общими полями и таблицей позиций.

**Шапка заказа:** номер, заказчик (с подсказками из справочника), название. Кнопка `i` открывает заметки к заказу; если заметка есть, кнопка подсвечивается.

**Срок работ:** начало и конец на карточке заказа. Пустой конец — нет дедлайна, заказ просто идёт. Кнопки «Начать сегодня» / «Закончить сегодня» ставят дату одним нажатием. Статус работ считается сам: без дат, запланирован, идёт сейчас, завершён (конец сегодня или раньше) или снят (все позиции отменены).

**Общие поля заказа** применяются сразу ко всем позициям: скидка %, статус, тип заказа, дата заказа, дата оплаты. Удобно, когда заказ оплатили целиком или сдвинули срок.

**Кнопка «Оплатить все типы»** записывает в каждую строку её итог и, если оплата покрывает сумму, ставит статус «оплачено».

**Таблица позиций** — столбцы: тип заказа, продукт, количество, единица, цена, скидка %, дата заказа, оплачено, дата оплаты, не оплачено, итог, статус. Даты — календарный день без времени. Итог, «не оплачено» и проценты считаются на лету. Позиции с «расходным» типом живут в отдельном блоке под таблицей — см. [Налоги и затраты](#налоги-и-затраты).

- Строки перетаскиваются мышью за левую ручку, порядок сохраняется в файле.
- Ширина любого столбца тянется за границу заголовка и запоминается в отчёте.
- В количестве, цене и скидке работают **формулы**: `2+3*4`, `1200/3`, `(5+2)*100`. Вместо `*` можно писать `x` или `×` (`3x250`), запятая сама превращается в точку. В ячейке остаётся формула, в итогах — результат.
- Кнопки в строке: дублировать (`⧉`) и удалить (`✕`). Правый клик по ручке перетаскивания открывает меню **«Заморозить позицию»**: строка уходит в блок **«Замороженные позиции»** (он появляется, только если есть хотя бы одна такая), значения сохраняются, но никуда не считаются — не в итоги заказа, не в дашборд, кассу, календарь, облако, снимок и CSV. Так можно спрятать позицию на потом, не удаляя её и не вводя заново. Тем же меню позицию возвращают в заказ.

**Фильтр** в тулбаре — кнопка с воронкой, как в календаре: Все, С долгом, Оплаченные, Этот месяц, Без цены — с количеством заказов в каждой группе.

**Сортировка:** сначала новые, сначала старые, по номеру, по заказчику, по сумме ↓.

**Действия с заказом:** «Снимок» (картинка для заказчика), «Дублировать», «Удалить». Кнопка «Снимок заказов» в тулбаре собирает снимок сразу по нескольким заказам.

## Раздел «Дашборд»

**KPI-плитки:** количество заказов и позиций, сумма к оплате после скидок (и отдельно — без отменённых), оплачено с процентом сбора, не оплачено.

**Инсайты** — восемь готовых выводов: выручка за месяц со сравнением с прошлым, прогноз до конца месяца по текущему темпу, средний чек, собираемость оплат, лучший заказчик, хит продаж, долги старше 30 дней и количество заказов за 30 дней против предыдущих 30. У метрик со сравнением есть чип тренда `+12%` / `−8%`.

**Графики:** выручка по дням (последние 14 дней) — несколько кривых (выручка, оплачено, долг, расход, чистыми), ряды включаются чипами в легенде; набор кривых у этого графика свой и запоминается. Рядом — распределение сумм по статусам, цвета берутся из справочника статусов.

**«Требуют внимания»** — позиции с долгом и заказы из чёрного списка. **«Последние заказы»** — быстрый переход к свежим заказам.

**Фокус заказа с телефона.** Когда с телефона открывают конкретный заказ, наверху дашборда появляется блок «с телефона» с цифрами именно этого заказа: кнопка «Открыть в заказах» ведёт к карточке, «Весь отчёт» возвращает общие показатели.

## Раздел «Аналитика»

**Фильтры мониторинга:** дата с/по (календарный день, без времени), поле даты (дата заказа или дата оплаты), группировка (дни, недели, месяцы), статус, тип заказа, заказчик, продукт, единица измерения, сумма от/до, галочка «Только долги». Пресеты периода: Сегодня, 7 дней, Этот месяц, Этот год. Кнопка «Сбросить» возвращает всё в исходное.

**Сравнение периодов A и B** — два независимых интервала с итогами по каждому и графиком сравнения метрик (каждая метрика в своей шкале, чтобы выручка не «съедала» количество заказов).

**График «Динамика»** строится по выбранной группировке. Те же ряды, что на дашборде: выручка, оплачено, долг, расход и чистыми; клик по легенде скрывает или показывает кривую. Выбор рядов у динамики свой и тоже запоминается.

**Таблица «Найденные позиции»** — все строки отчёта, попавшие под фильтры, с итогами по ним.

## Раздел «Касса»

Платёжный календарь и работа с дебиторкой — раздел о том, *когда* придут деньги, а не только сколько их всего.

**Настройки сверху:** срок оплаты в днях от даты заказа (0–365, по умолчанию 14) и горизонт прогноза (14, 30, 60 или 90 дней). Оба параметра хранятся в файле отчёта. Кнопка «Копировать сводку» кладёт в буфер текстовую выжимку по кассе — удобно отправить руководителю.

**KPI:** поступит за 7 дней (и за 30), просрочено с максимальной задержкой, средний фактический срок оплаты против договорного, вся дебиторка с процентом собираемости.

**Прогноз поступлений** — накопительный график с двумя линиями: план по сроку оплаты и реалистичный прогноз с учётом платёжной дисциплины заказчиков (насколько каждый из них исторически задерживает оплату).

**Долг по заказчикам** — круговая диаграмма, крупные должники отдельно, остальные в «Прочие».

**Платёжный календарь** — плитки по дням с суммами ожидаемых поступлений. Клик по дню фильтрует реестр дебиторки, повторный клик снимает фильтр.

**Старение дебиторки** — полоса и разбивка долга по корзинам: срок не наступил, просрочка 1–7 дней, 8–30, 31–60, больше 60 дней и отдельно позиции без дат. Под таблицей считается «безнадёжная зона» — доля долга с просрочкой больше 30 дней. Клик по корзине фильтрует реестр.

**Реестр дебиторки** — список неоплаченных позиций с ожидаемой датой, суммой и просрочкой. Действия в строке: отметить оплату одной кнопкой, скопировать готовый текст напоминания заказчику, открыть заказ, отфильтровать реестр по этому заказчику.

**«Кто должен»** — таблица по заказчикам: долг, число позиций, дисциплина (средняя задержка оплаты относительно срока).

## Раздел «Календарь»

Производственный календарь — когда заказы **начаты**, **идут сейчас** и **закрыты**. Это не касса: там про деньги, здесь про ход работ в цеху.

Вкладка стоит в боковом меню сразу под «Кассой». На карточке заказа те же даты начала и конца; календарь собирает их в три вида:

- **Таймлайн** — диаграмма Ганта выбранного отрезка дней. Сверху полоска периода по текущему фильтру: заказы линиями (как дорожка в Adobe Audition), рамка показывает, что видно сейчас. Полоски в навигаторе занимают свободную строку, если по датам не пересекаются; новая строка появляется только при наложении. Если раскрыть позиции заказа, дорожка подрастает и показывает их полоски. За крайними заказами слева и справа запас около месяца. При первом открытии сегодня в середине этого отрезка. Края рамки и колесо мыши над полоской меняют масштаб; колесо над линейкой дней листает период, рамка едет следом. Наведение на линейку дней подсвечивает столбец на всю высоту списка и показывает дату целиком (день недели, день месяц год; у выходного есть пометка). Пока тянете полосу или её край, дата висит рядом с курсором, столбец дня подсвечивается по всей высоте списка, длина линии меняется сразу, не после отпускания кнопки. Строки сверху вниз: сначала заказы в работе, затем более свежие даты — старые закрытые не всплывают наверх. Если конец работ позже сегодня, это дедлайн: золотой блик и ромб на правом краю полосы, в подписи «до …». Пустой конец — дедлайна нет, заказ просто идёт, это не просрочка. Заказ выбирают кликом по полосе, по названию слева или по пустому месту строки. Полоса заказа тянется мышью (сдвиг целиком), края меняют старт и финиш — на полосах нет подписей, номер и название стоят слева. Стрелка слева от названия раскрывает **позиции** заказа: у каждой своя полоса на тон темнее заказа, с теми же ручками длины и паузами. Оплаченная позиция зелёная, с долгом — оранжевая, а если заказ уже завершён и долг остался — красная. Та же логика у полосы самого заказа. Пока срок позиции не трогали, она длится как заказ; после правки остаётся своей и не выходит за границы заказа. Кнопка «Как у заказа» в правой панели возвращает наследование. Через выходные полоса рвётся и продолжается со следующего рабочего дня: у разрыва край ровный, без скругления. Если заказ висит месяц, а человек параллельно делает другие работы, внутри срока ставят **паузы**: Shift+клик по полосе в нужный день (или кнопка «Пауза в этот день» справа). Пауза — штриховой промежуток с теми же ручками, что у заказа: края меняют начало и конец паузы, перетаскивание сдвигает её, Shift+двойной клик снимает. То же на полосе позиции. Срок заказа (начало и конец) не сжимается: паузы — дырки внутри. Сдвиг всей полосы уносит паузы с собой. Если у заказа нет даты конца и паузу протянули до сегодня, она остаётся включённой и на следующие дни — заказ на паузе, пока паузу не снимут. Такие заказы на календаре помечены «На паузе»: в таймлайне у названия, на чипах, в неделе отдельным блоком и в правой панели. Сегодняшняя дата — красная линия через шапку и все строки, выходные, выбранный день и дни с перегрузом подсвечены тем же столбцом на всю высоту.
- **Классический** — сетка месяца с понедельника. Месяц и год выбираются в заголовке, стрелки ‹ › листают месяцы. В ячейке видны заказы этого дня и сколько их всего. Клик по дню выбирает его для быстрой постановки старта/финиша выбранному заказу и чтобы сделать день выходным или рабочим точечно.
- **Неделя** — семь колонок с понедельника: отдельно старты, «в работе» и финиши, плюс полоска загрузки дня.

**Сводка:** плитки больше не занимают строку. Справа от «Плана работ» круглая кнопка **i** — при наведении видно, сколько заказов идёт сейчас (пустой конец — нет дедлайна, это не просрочка), сколько стартов и финишей на текущей неделе, сколько ещё без дат, пик одновременной загрузки.

**Фильтры и вид:** слева кнопка с воронкой (все / идёт сейчас / запланированы / завершены / просрочены / без дат), рядом иконки видов: таймлайн (полоски Ганта), классический (сетка месяца), неделя (столбики дней). Глобально отмечают дни недели (по умолчанию сб и вс). Точечно — клик по дню и справа «Сделать выходным» или «Сделать рабочим»; такие дни на доске фиолетовые, обычные выходные — красные. На выбранный день можно оставить заметку. Настройки пишутся в файл отчёта. Строка поиска сверху тоже режет календарь. Справа на той же строке — период: ‹ › и название диапазона, затем иконки «сегодня», выходных (солнце), плана работ (лист) и сводки (**i**).

Доска таймлайна и правая панель занимают высоту окна программы; если заказов или текста больше, список крутится колесом. Навигатор периода и линейка дат остаются сверху, короткая подсказка — внизу, строки Ганта уезжают под линейку дат.

**Правая панель:** выбранный заказ или позиция (даты, список пауз со «Снять», начать/закончить сегодня, сдвиг на день, подставить крайние даты позиций или вернуть позицию «Как у заказа», снять даты, открыть карточку), выбранный день (выходной/рабочий, заметка, старт/финиш выбранного, пауза в этот день), список «в работе» и заказы без дат. Клик по заказу в панели переносит календарь к его началу. Кнопка «Подставить даты с позиций всем без дат» заполняет пустые сроки по датам строк заказа. «План работ» копирует текстовую сводку периода в буфер — удобно отправить в чат смены. Отмена (`Ctrl+Z`) откатывает правки дат, пауз, выходных и заметок.

Двойной клик по заказу открывает карточку. Вид, фильтр и выходные запоминаются в файле отчёта. Клавиши в разделе: `←` `→` период, `T` сегодня, `1`/`2`/`3` виды, `Enter` открыть выбранный. В таймлайне колесо над навигатором меняет масштаб, над линейкой дней — листает период, над строками — прокручивает список.

## Раздел «Калькулятор»

Нодовый калькулятор стоит в боковом меню сразу под «Календарём». На телефоне раздела нет: схемы собирают только на компьютере.

Слева меню заказов — оттуда заказ перетаскивают на поле (или кликают), и появляется нода со **всеми позициями** (доход, налог, затрата и замороженные). У каждой позиции свой выход с суммой, плюс общий «Итого». Цвета портов разные: доход — бирюзовый, налог — янтарный, затрата — розовый, замороженные — серые.

**Правый клик** по выходу позиции открывает меню доп. полей; они появляются как дочерние выходы под этой строкой и пропадают, когда связь с ними снимают:

- обычная и замороженная доходная позиция — количество, цена, скидка, оплачено, не оплачено;
- налог со своей суммой и затрата — количество, сумма за единицу;
- налог процентом (% от выручки / % от выручки − затраты) — процент.

Рядом в том же меню ноды-инструменты и список других блюпринтов:

- **Оператор** — четыре кнопки `+ − × ÷`, экран с результатом и один выход. Входов сначала два, максимум двадцать: следующий пустой вход появляется, только когда занят последний видимый.
- **Формула** — входы и выходы добавляет сам пользователь. Входы — только одна заглавная латинская буква (**A**…**Z**). По умолчанию входы **A** и **B**, выходы **C** и **D**: `A+B=C` и `(-40+A)*B=D`. У каждого выхода своя формула. Если два выхода спорят за одно имя с разными выражениями (например `A+B=C` и `A-B=C`), нода становится красной.
- **Процент** — два входа: число и `%`, выход `число × % / 100`.
- **Константа** — пользовательское число и один выход.
- **Результат** — экран как у оператора: показывает значение пришедшей связи, без арифметики. Имя задаётся в шапке ноды. Можно протянуть дальше через выход. Выходы всех нод «Результат» на схеме становятся выходами **ноды этой схемы**, когда её ставят на другой блюпринт.
- **Группа** — растягиваемая рамка без расчётов: имя, цвет, ручка размера справа внизу. Всё, что лежит внутри, едет вместе с группой; при отпускании ноды у границы она сама заходит внутрь или выходит наружу (порог 50%). Группы всегда под остальными нодами. Кнопка **∅** группы не удаляет.
- **Схема** — нода другого блюпринта. Её выходы — именованные результаты той схемы.

Справа от меню — поле схемы. Связь тянут **с выхода на вход или со входа на выход**; при наведении порты подсвечиваются. Цвет линии зависит от типа ноды (у позиций заказа — ещё и от вида строки). Если тянуть от входа к выходу: левый клик подключает как обычно, правый по выходу позиции открывает то же меню доп. полей. Если нода выделена, анимация бежит **только по входящей цепочке** — от исходных нод до выделенной. Заказы в меню — от новых к старым. С одного заказа можно вести сколько угодно связей. Снять связь — крестик на линии или на входе, либо `Alt`+клик по входу. Слева вверху поля — кнопка **↻** (полный пересчёт), переключатель **⛓** (тянуть цепочку входов) и **∅** (убрать ноды без связей; ноды «Схема» не трогает). Справа внизу — **навигатор схемы** (кнопка-глазик скрывает и показывает его): показывает все ноды и рамку текущего вида, обновляется при переносе, добавлении и удалении; клик или перетаскивание по навигатору переносит обзор. Колесо меняет масштаб, пустое место сдвигает чертёж. Крестик на ноде или `Delete` удаляет выбранную, `Esc` отменяет тянущуюся линию.

Сверху **вкладки схем**, как в браузере: одна строка, лишние листают колесом без вертикальной полосы; вкладки можно перетаскивать и менять местами. Имя схемы стоит в правом верхнем углу поля и там же его меняют. Всё это пишется в файл отчёта вместе с заказами и откатывается из истории.

## Раздел «Облако»

Интерактивная карта отчёта на canvas. Есть два режима: **система текущего файла** и **карта галактик** — все отчёты как отдельные галактики.

KPI (заказы, позиции, оборот, долг) стоят в шапке по центру, между подписью «живая физика» и строкой `LIVE RELATIONSHIP ENGINE`.

### Система текущего отчёта

Три уровня: **заказчик → заказ → позиция**. В 3D заказчик — звезда с мягким сиянием, заказ — планета, позиция — спутник. Сплошные линии — только эти связи. Пунктир между заказчиками не хранится в файле: это визуальная сетка (ближайшие на карте плюс общие типы работ). Расходные строки в облако не попадают.

**Четыре геометрии:**

- **Звёздные системы** — у каждого заказчика своя система: звезда в центре, заказы на орбитах, позиции — луны.
- **Орбитальное кольцо** — те же системы, выстроенные по кругу.
- **Финансовая ось** — заказы слева направо по дате, по вертикали — по сумме.
- **Созвездия работ** — позиции группируются по типу работы; между заказчиками с похожим портфелем рисуются пунктирные мосты.

**Визуальное кодирование:** цвет — статус, заказчик, оплата или тип работы; размер — сумма, долг, количество или одинаковые узлы. Красная дуга — доля долга. Кнопка `♨` включает тепловую карту долга. Кнопка **3D** поднимает карту в объём: левая кнопка вращает обзор, средняя сдвигает камеру. После выделения объекта центр орбиты переносится на него; сдвиг средней кнопкой отвязывает центр от выделения, чтобы масштаб и вращение шли за новым видом.

Выделение звезды приближает камеру так, чтобы вся её система попала в кадр; заказ — планета вместе со спутниками; спутник — ещё ближе.

**Поиск и фильтрация:** поле ищет по номеру, заказчику, названию, продукту, типу и статусу. Клавиша `/` сразу в поиск. Тумблер **«Только долг»** оставляет неоплаченные позиции. KPI считаются по видимой выборке.

**Управление картой:**

- колесо — масштаб; в 2D перетаскивание пустого места двигает карту, в 3D левая кнопка вращает, средняя сдвигает;
- узел можно перетащить, клик фиксирует его в инспекторе справа;
- двойной клик или `Enter` открывает заказ в разделе «Заказы»;
- стрелки переходят между соседними узлами, `F` вписывает весь граф, `T` — автотур по очагам долга;
- клик по мини-карте прыгает в область; `+` / `−` меняют масштаб, соседняя кнопка — полный экран, `⊙` вписывает граф;
- `Aa` скрывает подписи, `◉` ставит физику на паузу, `3D` переключает плоскую карту и объём;
- при выборе узла несвязанные данные приглушаются.

Инспектор показывает оборот, оплату, долг, собираемость, статус, тип, количество и дату. Из него можно открыть заказ, создать снимок, оставить на карте связи заказчика или центрировать узел.

### Карта галактик

Кнопка **«Галактики»** в панели облака. Каждый файл — отдельная галактика:

- отчёты из папки `Документы\FinMaster`;
- недавно открытые файлы, если их путь **не совпадает** с файлом из этой папки.

Размер зависит от объёма отчёта (заказы, позиции, размер файла). Типы разные, чтобы файлы отличались: спиральная, пересечённая, эллиптическая, линзовидная, клочковатая, неправильная. Имена галактик видны всегда, даже если в системе отчёта подписи выключены; кнопка `Aa` на карте галактик скрыта.

**Двойной клик** по галактике: камера влетает в диск, затем открывается этот отчёт (внутри — звёздные системы файла). На стартовом экране достаточно **одного клика**. Если текущий файл не сохранён, программа спросит: сохранить, открыть без сохранения или отмена.

Пока на телефоне открыта вкладка **«Отчёты»**, на компьютере показывается эта же карта галактик (на стартовом экране или в облаке, если отчёт уже открыт). Открытие файла с телефона не выкидывает компьютер с облака на дашборд.

Настройки геометрии, цвета и размера на карте галактик не нужны и скрыты. Карта всегда в объёме: тёмный космос, без сетки «пола».

Движок — Canvas 2D, без внешних библиотек: force-directed физика внутри отчёта, перспективный 3D-вид, тепловая карта долга, поддержка `prefers-reduced-motion`. Цвета и фон следуют теме; карта галактик всегда тёмная.

## Раздел «Заказчики»

Справочник контактов: имя, организация, телефон, почта, адрес, рейтинг звёздами, время совместной работы (считается с даты первого заказа) и количество заказов. Новые имена, введённые в заказах, попадают в справочник автоматически; имя из справочника подсказывается при заполнении заказа.

## Раздел «Справочники»

Четыре редактируемых списка, всё перетаскивается и переименовывается. Имена внутри каждого списка уникальны: одинаковое название ввести нельзя (без учёта регистра и пробелов по краям), кнопка «+» сама добавит суффикс `2`, `3`… Новое имя сразу подставляется во все заказы: статус и единица — в строки, тип заказа — в поле типа, продукт — в название позиции. То же с заказчиком в разделе «Заказчики».

- **Статусы заказа** — имя и цвет. Флаг «оплачено» помечает статус полной оплаты (такой статус в отчёте один). Замок защищает статус от массовой смены через общее поле заказа — так «Отменено» или «Черный список» не снесёт одним кликом.
- **Единицы измерения** — по умолчанию `шт.`, `м²`, `м`, `мин`; можно добавить свои.
- **Типы заказа** — по умолчанию Производство, Услуга, Поставка, Монтаж. У каждого типа есть две галочки — **Налог** и **Затрата** (можно выбрать только одну). Смена налога на затрату, затраты на налог, включение любой из пометок и снятие пометки спрашивают подтверждение в окне программы: строки в заказах от этого меняются. Тип с галочкой становится расходом: подробности ниже, в разделе [Налоги и затраты](#налоги-и-затраты).
- **Продукты** — название, единица и цена по умолчанию. Единица подставляется при выборе продукта. Цена из справочника — только если в строке ещё ноль; уже введённую сумму программа не затирает. В справочник попадает только готовое имя после выхода из ячейки, а не каждая буква по мере набора.

Статусы по умолчанию: Новый заказ, Выполняется, Ожидание, Не оплачено, Оплачено, Отменено, Аннулирован, Черный список.

## Налоги и затраты

Отметьте тип заказа галочкой **Налог** или **Затрата** в справочниках — и любая позиция с этим типом перестаёт быть выручкой и становится расходом.

**Как выглядит расход.** В карточке заказа такие строки уходят в отдельный блок **«Расходы заказа»** под основной таблицей. У них нет скидки, оплаты, даты оплаты и статуса — только тип, вид (налог или затрата), за что, расчёт, количество, сумма за единицу, дата и итог со знаком минус. Кнопка **«+ Расход»** в подвале заказа добавляет такую строку сразу; она появляется, только если хотя бы один тип отмечен галочкой. Достаточно сменить тип в обычной строке на «расходный» — строка сама переедет в блок расходов (и обратно).

**Налог процентом.** У новой строки налога по умолчанию стоит **% от выручки**. В столбце **«Расчёт»** три варианта:

- **% от выручки** — процент от всей выручки заказа (доходные строки после скидок);
- **% от выручки − затраты** — процент от выручки, из которой уже вычтены затраты;
- **своя сумма** — как у затраты: количество × сумма за единицу.

В режиме процента вместо количества и цены остаётся одно поле с процентом, а рядом подписана база: `% от 12 000 ₽`. База пересчитывается на ходу при правке любой строки заказа, а налог никогда не считается от другого налога. На телефоне то же самое: в редакторе строки появляются чипы «Своя сумма», «% от выручки», «% от выручки − затраты» и поле «Процент, %». В проценте, как и в остальных числах, работают формулы (`13+7`).

**Как считается.** Расход не попадает в выручку, оплаты и долги — он вычитается отдельной суммой:

- в подвале заказа: `расход −N ₽ · чистыми N ₽`;
- на дашборде: плитки **«Расходы»** и **«Чистыми»**, карточки выводов «Налоги и затраты» и «Чистая прибыль», вторая линия «Расходы» на графике динамики;
- в аналитике: вторая линия на графике, столбцы «Расход» и «Чистыми» в сравнении периодов, отдельная строка итогов под таблицей;
- на телефоне: свой блок «Расходы» в заказе, плитки «Расход» и «Чистыми» в сводке, полосы «Налоги и затраты» и «Чистыми».

**Куда расход не попадает.** В кассу (расход не создаёт дебиторки) и во внутреннюю карту облака (звёздные системы текущего файла). В снимке для заказчика расходы по умолчанию скрыты, но их можно включить полем **«Налоги и затраты»** — см. [Снимок для заказчика](#снимок-для-заказчика). В экспорте CSV расход виден всегда: столбец **«Вид»** показывает «доход», «налог» или «затрата», сумма попадает в столбец «Расход».

Переименование типа, статуса, единицы, продукта или заказчика в справочниках сразу подтягивает новое имя во все существующие строки и заказы, так что галочка налога/затраты и цвет статуса не «отклеиваются» от позиций.

## Снимок для заказчика

Красивая картинка или текст с составом заказа — то, что отправляют клиенту вместо скриншота таблицы.

- **Заголовок** снимка задаётся вручную.
- **Оформление** — 7 тем: Изумруд, Графит, Индиго, Золото, Вишня, Минимал, Ночь.
- **Поля** — 17 доступных: номер, имя заказчика, организация, название, тип/работа, продукт, количество, дата заказа, статус, цена, скидка, сумма позиции, оплачено, не оплачено, дата оплаты, итоги заказа, налоги и затраты. Готовые наборы: «Только работы» (без цен — для согласования состава), «Счёт» (с ценами и итогами), «Все поля».
- **Налоги и затраты** — отдельное поле. Пока оно выключено, расходные позиции в снимок не попадают (так было раньше по умолчанию). Если включить, они встают в таблицу вместе с обычными строками: в столбце типа приписано «налог» или «затрата», сумма идёт с минусом, вместо количества у процентного налога стоит `10 %`, а вместо цены — база процента. Скидки, оплаты и статуса у таких строк нет — в этих столбцах прочерк. Итог таблицы становится суммой **после** вычета расходов, а в строке итогов добавляются `расходы −N ₽` и `к оплате N ₽`. Работает одинаково в PNG, тексте, на телефоне и в Telegram-боте.
- **Скрытие** подписей полей и даты формирования — для совсем лаконичного вида. В подписи «Сформировано» остаётся дата и время; в самих заказах и позициях время не показывается.
- **Выбор заказов и строк** — можно исключить отдельные позиции из снимка. Расходные строки в списке подписаны «налог» / «затрата», чтобы их было видно. Замороженные позиции в снимок не попадают.
- **Предпросмотр** обновляется на ходу. Количество, скидка и проценты округляются до сотых, без «хвоста» вроде `1,333333`.
- **Результат:** сохранить PNG, скопировать PNG в буфер, скопировать текстом.

Набор полей и выбранная тема запоминаются в файле отчёта.

## Командная палитра

`Ctrl+K` открывает палитру: строка ввода и список команд с группировкой. Навигация `↑` `↓`, выполнение `Enter`, закрытие `Esc`.

Палитра умеет:

- переходить в любой раздел — Дашборд, Заказы, Аналитика, Касса, Календарь, Калькулятор, Облако, Заказчики, Справочники;
- выполнять действия — сохранить, сохранить как, открыть, создать, экспорт CSV, снимок заказов, отмена/повтор, свернуть боковую панель, консоль сети, подсказка;
- открывать кассовые сценарии — например, показать просроченные долги или скопировать сводку;
- сразу открывать календарь на заказах в работе;
- искать по содержимому отчёта: наберите номер заказа, имя заказчика или название продукта — палитра предложит перейти к нужной карточке.

**Отмена и история.** Между стрелками отмены и повтора — часы. В панели видны снимки после каждого действия: подпись (заказ, календарь, справочник…) и устройство — «ПК» или имя телефона. `Ctrl+Z` / `Ctrl+Y` ходят по этим снимкам, можно ткнуть конкретный. Если отойти на несколько шагов назад и сделать новое действие, более поздние снимки пропадают; пока новой правки нет, к ним ещё можно вернуться. Сколько снимков хранить, задаётся в той же панели (по умолчанию 40). Кнопка «Все истории отчётов» открывает список папок: путь к файлу (и в FinMaster, и снаружи), пометку если файл уже удалён, число снимков и размер; ненужные истории можно стереть. Снимки лежат в `Документы\FinMaster\history\<название отчёта>\` — `meta.json` и отдельные JSON на каждый снимок. При открытии отчёта эта папка подхватывается целиком, старые снимки не сбрасываются. Правка с телефона тоже попадает в историю.

## Управление с телефона

Кнопка **«Телефон»** в верхней панели. Телефон подключается напрямую к компьютеру — промежуточных серверов нет.

1. Нажмите **«Включить доступ»** — появится QR-код и ссылка вида `http://192.168.0.10:17891/m?t=…`.
2. Наведите камеру телефона на код или откройте ссылку в мобильном браузере.
3. Добавьте страницу в закладки: токен и порт постоянные, второй раз сканировать не нужно.

Под QR-кодом — чипы с локальными IP-адресами и «Интернет»: ими выбирается, куда ведёт код, если у компьютера несколько сетевых адресов.

**В окне подключения:**

- **Включать доступ при запуске программы** — доступ поднимается сам вместе с FinMaster.
- **Через интернет (ngrok)** — см. следующий раздел.
- **Токен ngrok**, **Telegram**, **Устройства** — три сворачиваемых блока, чтобы окно не разрасталось. У заголовков «Токен ngrok» и «Telegram» горит точка-индикатор: серая — токен не сохранён, зелёная — сохранён, голубая — работает прямо сейчас (туннель поднят / бот слушает), красная — токен есть, но сервис вернул ошибку. Наведите курсор — подсказка расскажет подробности.
- **Устройства** показывают подключённые телефоны в реальном времени: заголовок блока и список обновляются сами, пока окно открыто — видно имя (его задают на телефоне), кто онлайн, с какого адреса и когда заходил последний раз. Любое устройство можно забыть.
- **Консоль** — плавающее окно с сетевыми событиями: включения доступа, телефоны в сети, синхронизация отчёта, команды, Telegram и ngrok. Перетаскивается за заголовок, вызывается кнопкой в окне подключения, из палитры «Команды» или `Ctrl+Ё`. `Esc` закрывает консоль.
- **Новая ссылка** — сбрасывает только токен сессии телефона: старые закладки перестают работать, устройства отключаются. Токены ngrok и Telegram и сам бот не трогаются. Кнопка **«Открыть»** в боте (меню и клавиатура) сразу получает новый адрес, в чат приходит короткое сообщение. Подтверждение — в том же стиле, что остальные окна программы.
- **Выключить доступ** — закрывает сессию. Токены ngrok и Telegram при этом сохраняются, вводить их заново не придётся.

Кнопка `i` в заголовке окна открывает отдельное руководство по подключению.

Всё, что делается на телефоне, сразу видно на компьютере — и наоборот. Переход по разделам тоже зеркалится: открыли на телефоне «Заказы» — на компьютере откроется тот же раздел, открыли конкретный заказ — компьютер перейдёт на дашборд и покажет цифры именно этого заказа. Фильтры сводки (период, долг/оплата, статус) на дашборде компьютера следуют за телефоном. Калькулятор на телефон не выводится — схемы собирают только в окне программы.

Если на компьютере нет открытого отчёта, телефон сразу показывает вкладку «Отчёты»: папка FinMaster и недавние файлы. На компьютере в этот момент открывается карта галактик (на стартовом экране или в облаке). Выбор другого отчёта на телефоне открывает его в окне программы и переключает телефон на вкладку **«Заказы»**. Удаление с телефона или в проводнике сразу убирает файл со стартового экрана компьютера и из списка на телефоне. Если текущий отчёт не сохранён, смена галактики на компьютере спрашивает подтверждение.

Каждое устройство можно назвать: имя видно в списке «Устройства». Кнопка `i` на телефоне показывает модель, систему и браузер.

## Доступ через интернет (ngrok)

Чтобы заходить не только из своей Wi-Fi:

1. Скачайте ngrok с [ngrok.com/download](https://ngrok.com/download), распакуйте и добавьте программу в `PATH`.
2. Зарегистрируйтесь на ngrok.com и скопируйте **Your Authtoken** из кабинета.
3. В окне «Телефон» включите **«Через интернет (ngrok)»**, вставьте токен в блок «Токен ngrok» и нажмите **«Сохранить и включить»**.
4. QR сменится на адрес вида `https://….ngrok-free.app/m?t=…` — его и сохраняйте в закладки телефона.

Нюансы: на бесплатном тарифе адрес меняется после перезапуска — скопируйте ссылку заново (или спросите её у Telegram-бота). При первом открытии ngrok может показать свою страницу-предупреждение — нажмите **Visit Site**. Токен хранится только на этом компьютере и не забывается при выключении тумблера.

## Telegram-бот

Бот — отдельный вход в те же отчёты: не нужно открывать браузер на телефоне. Пока FinMaster запущен, из чата можно смотреть файлы, заказы и собирать снимки. Если включён интернет (ngrok), тот же мобильный интерфейс открывается **внутри Telegram** как Mini App.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. В окне «Телефон» → блок **Telegram** вставьте токен и нажмите **«Запомнить токен»**. Chat id заполнять не обязательно — он запомнится при первом `/start`.
3. Включите доступ с телефона и тумблер **Через интернет (ngrok)** — Mini App работает только по HTTPS. Локальный адрес `http://192.168.…` Telegram внутрь чата не откроет.
4. В Telegram нажмите **/start**.

Кнопки внизу чата: **Отчёты**, **Заказы**, **Открыть** (Mini App, если есть HTTPS), **Ссылка**, **Новая ссылка**, **Меню**. **Новая ссылка** сначала спрашивает подтверждение, затем выпускает тот же новый адрес, что кнопка в окне «Телефон»: старые закладки отваливаются, бот остаётся на связи, «Открыть» обновляется. Слева в поле ввода — кнопка меню бота **Открыть**. Команды: `/start`, `/reports`, `/orders`, `/link`, `/newlink`.

Адрес Mini App обновляется сам, когда меняется ngrok или токен сессии. Если туннель ещё не готов или доступ выключен, кнопка меню снова показывает обычные команды.

**Отчёты** — тот же список, что на стартовом экране: папка `Документы\FinMaster` и недавние файлы. Выбор отчёта открывает его заказы. Если этот файл сейчас открыт на компьютере, бот показывает живые данные вместе с несохранёнными правками. Кнопка «Открыть на компьютере» просит программу показать тот же файл в окне.

**Заказы** — список с суммой и долгом, фильтры «все / с долгом / оплаченные», страницы. Напишите номер, имя заказчика или продукт — бот отфильтрует. Карточка заказа: заказчик, итог, оплата, долг, все позиции и заметки.

**Снимок** — как на компьютере, без урезанного режима:

- наборы «Для работы», «Как счёт», «Коротко», «Все поля» и ручное включение каждого из 16 полей;
- семь тем: Изумруд, Графит, Индиго, Золото, Вишня, Минимал, Ночь;
- скрыть подписи и дату формирования, свой заголовок;
- выбрать позиции и добавить несколько заказов на один снимок;
- результат — картинка PNG или текст (длинный текст приходит файлом).

**Ссылка** — кнопка «Открыть приложение» (Mini App по HTTPS) или «Открыть FinMaster» (браузер по HTTP), актуальный адрес, тип подключения (`ИНТЕРНЕТ` / `ЛОКАЛЬНАЯ СЕТЬ`) и предупреждение, если на компьютере выключен доступ или ngrok. На бесплатном ngrok при первом заходе может появиться страница **Visit Site** — это ограничение туннеля, не FinMaster.

Бот отвечает только тому чату, который первым написал `/start` (или чей chat id указан в окне «Телефон»). Кнопка **«Отправить ссылку сейчас»** по-прежнему шлёт ссылку, не вставая из-за компьютера.

## Мобильный интерфейс

Открывается по ссылке `/m?t=<токен>` — из браузера или как Telegram Mini App. Внутри Telegram приложение сразу запрашивает полный экран (как игры): шапка мессенджера становится прозрачной, остаётся системный крестик закрытия. Нужен Telegram с поддержкой Mini App fullscreen (примерно с конца 2024). Наверху — отмена, повтор и меню, ниже — строка синхронизации с состоянием связи.

В меню `⋯` справа вверху — квадратные кнопки рядом с заголовком и широкая «Сохранить на компьютере», ниже плитки: снимок, новый отчёт, ссылка, отчёты. В браузере слева от темы — полный экран. Справа от темы — проверка связи с компьютером: запрос к программе и сообщение, есть ли подключение. Внутри Telegram полный экран скрыт (Mini App и так развёрнут), на его месте — ярлык **на домашний экран**, как у игр. Тот же пункт есть в «Отчёты» → «Это устройство». Если Telegram ответит, что ярлык недоступен, в [@BotFather](https://t.me/BotFather) включите Mini App и задайте иконку: `/mybots` → бот → Bot Settings → Configure Mini App.

**Пять вкладок:**

- **Заказы** — поиск, сортировка, воронка фильтра (все / с долгом / оплачены / этот месяц) и список заказов. На карточке — номер и название заказа, суммы и цветные точки статусов всех позиций; одновременно видно не больше 10, остальные плавно качаются туда-сюда с замедлением на краях. Кнопка `+` создаёт заказ.
- **Календарь** — на телефоне два вида иконками: месяц и неделя (таймлайн только на компьютере). Сверху плитки «Идёт / Без дат», затем слева виды и справа воронка фильтра, ниже иконка «сегодня» и ‹ › с месяцем или неделей. Выходные те же, что заданы на компьютере: обычные — красные, точечные — фиолетовые. В неделе видны только рабочие дни: если суббота глобально рабочая, её заказы попадают в список. Заказ на выходной не ставится: диапазон обрывается до выходного и продолжается со следующего рабочего. Дни паузы, отмеченные на компьютере внутри срока заказа, в сетке тоже не считаются работой. Если пауза доведена до сегодня у заказа без даты конца, она держится и на новые дни, пока её не снимут. На день можно оставить заметку; выбранный день в сетке месяца и в неделе обведён. Статус работ на карточках и в сетке месяца тот же, что на компьютере: идёт сейчас, запланирован, завершён, без дат. Неделя идёт сверху вниз от позднего дня к раннему (для диапазона 21–27 сверху 27). Фильтр «Без дат» показывает только список без дат, не размазывает их по дням календаря. Пустой конец — нет дедлайна, заказ не просрочен. Если даты ещё нет — «Начать сегодня» / «Закончить сегодня»; если уже стоит — «Сменить начальную/конечную дату» и «Убрать». Открытие календаря на телефоне переключает тот же раздел на компьютере.
- **Сводка** — KPI и выводы по отчёту. Три кнопки фильтров (период, заказы, статус) открывают список вариантов; выбранное видно на кнопке. Внизу блок **«Кто должен»** — карточки с номером и названием заказа, суммой долга и заказчиком. Те же фильтры сразу видны на дашборде компьютера.
- **Снимок** — тот же снимок для заказчика, что и на компьютере: выбор заказа, 4 темы (Бирюза, Золото, Минимал, Ночь), наборы полей, заголовок, скрытие подписей и даты. Список позиций свёрнут по умолчанию (в шапке видно, сколько строк в снимке) — так кнопки отправки остаются рядом. Свайп влево или вправо листает заказы в том же порядке, что в списке. Если открыть снимок из заказа или другой вкладки, в шапке появляется **‹** — возврат туда, откуда пришли. В браузере картинку можно отправить через «Поделиться» или сохранить PNG в загрузки. Внутри Telegram Mini App системное «Поделиться» и сохранение в Загрузки не работают (WebView не отдаёт файл) — снимок уходит ботом: **«Поделиться в Telegram»** открывает выбор чата, **«Прислать PNG в чат»** кладёт файл в переписку с ботом, откуда его можно сохранить и переслать.
- **Отчёты** — если на компьютере открыт файл, видны название, валюта и сохранение. Дальше общий список папки FinMaster (открыть или удалить в корзину), недавние файлы и блок устройства: имя на компьютере, сведения о телефоне, полный экран, постоянная ссылка и отключение. Список папки обновляется сам, если файл появился или исчез в проводнике. Выбор другого отчёта сразу подтягивает файл и открывает вкладку **«Заказы»**.

Калькулятора на телефоне нет: нодовые схемы собирают только в окне программы.

**Новый отчёт** спрашивает название и сохраняется в `Документы\FinMaster`. Если файл с таким именем уже есть, программа предложит другое. Пока на компьютере ничего не открыто, телефон остаётся на вкладке «Отчёты» — можно выбрать файл из папки или из недавних.

**Карточка заказа** на телефоне: липкая шапка с номером и названием заказа, список позиций, кнопки «+ Позиция», «Снимок для заказчика», «Дублировать заказ», «Удалить заказ». Заказчик и даты начала/конца работ — в блоке «Данные заказа». Замороженные позиции, если они есть, стоят отдельным блоком внизу и в итоги не входят; вернуть их можно из редактора строки. Вкладка «Заказы» держит открытую карточку и прокрутку: уход на сводку, календарь или снимок и возврат снова показывает тот же заказ в том же месте страницы. К списку возвращает **‹**. Свайп влево — следующий заказ из текущего списка (с учётом поиска, фильтра и сортировки), вправо — предыдущий. Строки позиций и расходов переставляются за ручку слева, как на компьютере.

**Редактор позиции** — отдельная панель на весь экран со всеми полями строки (тип, продукт, количество, единица, цена, скидка, даты, оплата, статус). Стрелки `‹` `›` и свайп влево/вправо листают позиции того же заказа, не закрывая редактор. В количестве, цене и скидке те же формулы, что на компьютере (`2+3×4`, `1200/3`). На телефоне открывается своя клавиатура: цифры и действия; в поле остаётся формула, при уходе фокуса виден результат.

**Отмена и повтор** работают с телефона и применяются к документу на компьютере. В меню под автосохранением — **История**: список снимков только для просмотра (подпись и устройство). Лимит и удаление папок — на компьютере. Изменения летят в обе стороны. Если на компьютере включено автосохранение, правки с телефона сами записываются в файл — не нужно щёлкать галочку на телефоне. Если связь пропала, строка синхронизации пишет «нет связи с компьютером». Как только любой запрос снова проходит (смена вкладки, открытие отчёта, проверка связи, опрос), надпись снимается — она не зависает после включения программы обратно. Когда страница закрывается или нажимают «Отключиться», компьютер сразу видит, что устройство ушло.

## Безопасность

- Доступ с телефона включается вручную и работает, пока открыта программа.
- Telegram-бот показывает отчёты только тому чату, который привязан в окне «Телефон». Не публикуйте бота в открытых группах.
- Ссылка содержит токен сессии; без него запрос с другого адреса отклоняется.
- С телефона доступен **только мобильный интерфейс** — рабочий стол программы через туннель не открывается.
- Токены ngrok и Telegram пишутся в конфиг атомарно и держатся в памяти программы. Пустая строка или опечатка их не затирает — заменить можно только новым действительным токеном.
- «Новая ссылка» мгновенно обнуляет доступ для всех прежних устройств, но бот Telegram продолжает работать.

## Где хранятся настройки

Настройки программы: `%APPDATA%\FinMaster\config.json` (на не-Windows — `~/.config/FinMaster/config.json`).

В нём: список недавних файлов, флаг автосохранения, последняя папка, тема и блок `remote` — токен сессии, порт, автозапуск доступа, список запомненных устройств (до 20), настройки ngrok и Telegram (токен бота, chat id привязанного чата).

Тема, вид стартового экрана (список или галактики) и список недавних дополнительно кешируются в `localStorage` интерфейса. Сами отчёты лежат там, где вы их сохранили: в файле — заказы, справочники, вид календаря, **выходные** (дни недели и точечные даты) и схемы калькулятора. Новые файлы с телефона по умолчанию пишутся в `Документы\FinMaster` — программа эту папку не подменяет и чужие каталоги не трогает.

## API для разработчика

Все маршруты локальные. Запросы с чужих адресов проходят только к мобильной части и только с токеном.

| Маршрут | Назначение |
| --- | --- |
| `GET /` | интерфейс компьютера |
| `GET /m` | мобильный интерфейс |
| `GET /api/bootstrap` | стартовые данные: тема, недавние, папка FinMaster, автосохранение, состояние доступа |
| `POST /api/dirty`, `/api/autosave`, `/api/theme` | состояние документа и настройки |
| `POST /api/dialog/open`, `/dialog/save`, `/dialog/export`, `/dialog/png` | системные диалоги |
| `POST /api/write`, `/write-text`, `/write-bytes` | запись отчёта, текста и PNG |
| `GET /api/library` | список отчётов в папке FinMaster |
| `GET /api/library/watch` | длинный опрос: папка FinMaster изменилась (только компьютер) |
| `POST /api/library/delete` | отправить отчёт из папки FinMaster в корзину (только с компьютера) |
| `POST /api/open-folder` | открыть папку FinMaster в проводнике |
| `POST /api/open-path`, `/api/recent/remove` | открыть файл по пути, убрать из списка недавних |
| `POST /api/clipboard-text`, `/api/clipboard-png` | буфер обмена |
| `POST /api/remote/start`, `/remote/stop` | включение и выключение доступа с телефона |
| `POST /api/remote/address` | выбор адреса для QR-кода |
| `POST /api/remote/ngrok` | тумблер и токен ngrok |
| `POST /api/remote/telegram` | токен бота, chat id, отправка ссылки |
| `POST /api/remote/rotate`, `/remote/forget` | новая ссылка, забыть устройство |
| `GET /api/remote/info` | состояние доступа, список устройств и клиентов |
| `POST /api/remote/publish`, `/remote/push` | обмен документом между компьютером и телефоном |
| `GET /api/remote/pull`, `/remote/session` | получение изменений, списка отчётов и данных сессии |
| `POST /api/remote/command`, `/remote/nav` | команды (сохранить, открыть, новый, удалить, отмена, повтор) и зеркалирование навигации |
| `POST /api/remote/leave` | телефон сообщает об отключении |
| `POST /api/quit` | закрытие программы |

## Решение проблем

**Телефон не открывает локальную ссылку.** Проверьте, что телефон и компьютер в одной Wi-Fi, и разрешите Python в брандмауэре Windows для частной сети. Если у компьютера несколько адресов, попробуйте другой IP-чип под QR-кодом.

**Ссылка была, а теперь не работает.** Скорее всего адрес ngrok сменился после перезапуска или кто-то нажал «Новая ссылка». Откройте окно «Телефон» и скопируйте актуальную ссылку либо запросите её у бота.

**ngrok не включается.** Программа ngrok должна быть в `PATH`, а токен — вставлен в блок «Токен ngrok». Ошибку подключения окно показывает текстом под кнопкой.

**Бот молчит.** Проверьте токен из @BotFather и что программа запущена. После смены токена напишите боту `/start` заново — chat id подставится сам.

**Бот пишет, что доступ выключен.** Так и задумано: он не включает доступ или ngrok молча. Включите нужные тумблеры в окне «Телефон» и нажмите «Получить ссылку» ещё раз.

**Порт занят.** FinMaster сам подберёт свободный порт и запомнит его — QR-код и ссылка обновятся.

**Интерфейс открылся в браузере, а не в своём окне.** Не установился `pywebview`. Выполните `python -m pip install pywebview`. В браузерном режиме сохранение идёт через скачивание файла.

**Автосохранение не срабатывает.** Отчёт ещё ни разу не сохраняли вручную — программа не знает путь. Сохраните файл один раз, дальше галочка заработает.

**Удалили отчёт по ошибке.** Файл в корзине Windows, не стёрт навсегда. Восстановите его из корзины и снова откройте в FinMaster. Удалять из списка можно только файлы из папки `Документы\FinMaster`.

**При запуске нужна консоль.** Обычный старт идёт через `run.bat` без чёрного окна. Чтобы видеть сообщения Python, задайте `FINMASTER_CONSOLE=1` и запустите `python launch.py`.
