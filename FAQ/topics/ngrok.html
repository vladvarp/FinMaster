Интернет через ngrok

Так на телефон можно заходить не только из своей Wi-Fi. Пока компьютер включён, FinMaster запущен и туннель работает, ссылка доступна из другой сети.

Поставить ngrok

  1. Проще поставить ngrok из Microsoft Store: после установки он уже находится по имени, отдельно добавлять его в PATH не нужно.
  2. Либо скачайте архив с ngrok.com/download, распакуйте ngrok.exe в постоянную папку и добавьте эту папку в PATH пользователя. После этого перезапустите FinMaster.
  3. Зарегистрируйтесь на ngrok.com и скопируйте Your Authtoken из личного кабинета.
  4. Откройте в окне «Телефон» блок «Токен ngrok» → «Управление токенами», добавьте Authtoken и при желании задайте ему название. Выберите его в списке, затем включите «Через интернет (ngrok)».
  5. QR-код сменится на адрес вида https://….ngrok-free.app/m?t=…. Его можно сохранить в закладки телефона.

Основной блок ngrok

Блок показывает сохранённый токен, состояние процесса ngrok.exe и состояние туннеля. Анимация ниже последовательно демонстрирует выключенное состояние, запуск, подключение, остановку и ошибку. Этап можно выбрать вручную.

Управление токенами

В одном списке можно хранить несколько Authtoken от разных аккаунтов ngrok. Для каждой записи задаётся понятное название. В списке отображаются только первые шесть символов токена; активная запись помечена отдельно.

Состояние процесса

Рядом с заголовком «Токен ngrok» отображается состояние процесса ngrok.exe:

  • Процесс запущен — процесс обнаружен в Windows.
  • Процесс не запущен — работающий процесс не найден.

Проверка выполняется локально на компьютере, без обращения к серверу ngrok. Состояние обновляется автоматически, пока открыто окно «Телефон».

Если процесс ещё работает, но доступ или сам туннель выключен, может появиться кнопка «Завершить принудительно».

Кнопка запускает ngrok_stop.bat. Если FinMaster работает без прав администратора, Windows покажет запрос UAC. Подтвердите его, чтобы разрешить завершение процесса.

Батник завершает все процессы с именем ngrok.exe, в том числе запущенные отдельно от FinMaster, а также их дочерние процессы.

Если ngrok не работает

На бесплатном тарифе адрес может меняться после перезапуска туннеля. Тогда скопируйте новую ссылку или запросите её у Telegram-бота.

При первом открытии ngrok может показать собственную страницу-предупреждение — нажмите Visit Site.

Токены хранятся на этом компьютере в зашифрованном файле. Выключение туннеля не удаляет выбранный токен. При переключении на другой токен FinMaster сначала останавливает ngrok, затем запускает его заново с новым Authtoken. Если процесс не завершился, программа предложит принудительно запустить ngrok_stop.bat.

Если FinMaster сообщает, что ngrok не установлен, программа не нашла ngrok.exe в PATH. После установки из Microsoft Store или изменения PATH перезапустите FinMaster.

Проверка процесса и проверка доступности туннеля — разные вещи. Надпись «Процесс запущен» означает только то, что Windows обнаружила ngrok.exe. Для проверки соединения используйте кнопку «Проверить связь».
