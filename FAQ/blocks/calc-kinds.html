Карточка заказа из отчёта. У каждой позиции свой выход: доход бирюзовый, налог янтарный, затрата розовый, замороженная строка серая. «Итого» — сумма позиций, здесь 18 000 + 9 000 = 27 000. Кнопка Σ добавляет выход на сумму всех позиций одного типа. Правый клик по выходу открывает доп. поля этой строки. С заказа можно провести сколько угодно линий.

В шапке ноды остаются имя самого планировщика и цвет текущей планировки. Переключение и создание планировок перенесены в редактор: выпадающий список расположен слева от названия открытой планировки. У каждой свой цвет и свой блок выходов: сверху чертёж, ниже числа этой планировки. Плёнка показывает чертежи подряд. Цвет берётся из палитры по числу планировок и меняется палитрой в шапке для текущей. Выход «Чертёж» уходит только в проёмы или электрику. Выход «Высота стен» отдаёт высоту в метрах. В примере комната 4×3 м, высота 2,7 м: пол 12 м², стены суммарно 37,8 м². Стена 1 — 4×2,7 = 10,8 м², её включили отдельно. Для каждой стены можно включить «Погонаж»: вместо площади будет выводиться высота стены в метрах; тумблер рядом переключает значение на длину стены. По умолчанию выбрана высота. «3 стены» — сумма трёх стен из четырёх: 29,7 м². Высота стен появляется среди выходов только при включённой галочке «На ноду» в разделе «Параметры». Развёртка в редакторе строится сама.

Группа

Рамка, не расчёт. Портов нет, число сквозь неё не идёт. Имя и цвет только чтобы собрать кусок схемы глазами. Ноды внутри едут вместе с рамкой. Клик по «Группа» при выделенных нодах ставит рамку вокруг них. Кнопка ∅ группу не удаляет.

Комментарий

Комментарий

Записка на поле. Портов нет, в сумму не входит. Кнопка ∅ её не удаляет: иначе текст без линий пропал бы при первой же чистке.

Точка

Перевалочный пункт линии. Число и чертёж проходят дальше без изменения. Пустая точка принимает любую линию. Пустую точку можно поставить на связь: линия рвётся на вход и выход. Удаление склеивает вход с выходом. Если выходов несколько, первое удаление их подсвечивает: клик оставляет выбранный, повторное удаление — первый.

Сумма

Один вход. Число и чертёж проходят на выходы. Заголовок правится в шапке, как имя у других нод. Название входа берётся у линии, пока его не изменили карандашом справа. Схема

Смета кухни
Смета 28 500

Это другая схема, поставленная сюда одной карточкой. Выходы — её видимые результаты, по приоритету: меньшее число выше. Число пишется рядом с портом. Чертёж приходит миниатюрой пола, и этот порт стыкуется только с чертежом. Глаз на результате прячет этот выход. Своих входов у ноды нет. Схема не может включить сама себя: такая карточка помечается ошибкой.
